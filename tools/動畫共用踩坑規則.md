## 1. 人物動作要合真實邏輯（老師最常退件的地方）

1. **拿東西先查真實拿法、寫成表、再擺**：每件器具寫「哪隻手／手心朝哪（世界方向）／拇指在器具哪一側／哪幾指彎多少／器具碰到手的哪裡／怎麼到嘴或臉」。筷子、叉子、杯子、筆、湯匙、牙刷都一樣。（11/20 台灣早餐片兩次退件：筷子拿法錯、左右手像鏡像。）
2. **左右手是鏡像**：同一個外積公式，右手得到手背、左手得到手心 → Mixamo 骨架 `PALM_SIGN` 右 −1、左 +1。手部函式一律用共用檔（桌上微縮：`tabletop/src/hands.py`），不要各片複製一份。
3. **第一批檢查圖固定有手部特寫**：兩個角度（前斜方＋側面）、**不開景深**、長焦距；手心方向、拇指位置、手指真的握住都對了才看其他。
4. **道具由接觸驅動**：手碰到才動、放下碰到桌面才鬆手；動作結束手上不留道具；拿起前後位置差（`fork_jump` 之類）印出來檢查。
5. **嘴的位置跟著頭轉**（用頭骨座標記下嘴的偏移），不要用「臉前方估一點」；器具從臉的側面碰嘴角；杯子在眼睛下面；**手和道具不擋臉**，也不要在動作中途抬到下巴前（翻書封面時手跟著封面邊緣抬到下巴高度，11/20 英國片被抓到）。
6. **姿勢中途和結尾也要抽格**：「拿著東西停在半空」的姿勢若太靠近胸口、太低，IK 會把前臂扭成麻花（11/20 西班牙片收叉子）；停的位置放在自然處（例如盤子正上方），每個動作的開始、中間、結束都要看。
7. **Q 版比例**：手臂很短（約 14 mm／學生 7 cm），道具要放在桌子近緣、人往前坐、從側面接近嘴；桌面在胸口高度是可以的（台灣片已定案）。
8. **人物永遠面向鏡頭**；上下車、走到門口等會背對鏡頭的動作，改成切鏡頭或側走。桌上微縮 3D 人物不做嘴巴（嚼＝頭小點兩下）；2D 角色怎麼對嘴見第 9 類。
9. **樂器、文具、運動器材先上網查正確姿勢，動詞照字面演** → 憑感覺擺，握筆退件 5 輪、吹直笛被退 → 握筆照「動態三指握法」：筆斜靠虎口約 50°、拇指＋食指指腹捏在離筆尖約 1–2.5 cm、中指在下面托、筆尖在紙上，先定筆再逐指 IK；直笛左手在上、右手在下、拇指在背面、約 45°、手肘下垂；「跑」就是跑，不能做成跳。（Free Time 11/14，`output/whatif-ken-freetime/rdq/RDQ-spec-whatif-ken-freetime-v2-fixes-20261114.md`；What if Ken v1 回饋 11/13，總覽 A9）
10. **交通工具車頭朝前進方向、騎乘用坐姿** → Tripo 載具車頭方向各不相同，yaw 修正角填反 180° 會「倒車」；站姿立牌放在座椅上像站在車上 → 每台載具的修正角寫進 `yaw.json`，先渲一張「俯視排排站」方向檢查圖，再抽「移動中 3 格」看車頭；騎乘用側面坐姿（坐座椅、手握把、腳在座墊前下方踩踏板、曲柄跟著轉，車把接在龍頭上，車架照角色腿長／臂長做，2D 用腳踝 IK）；上下車改成走到車門旁淡出淡入，不要縮小跳進車裡。（影片 8 11/09，`output/sci-fi-teachers/rdq/RDQ-spec-video8-tabletop-logic-fix-20261109.md`；Free Time 11/14；感恩節 35 句 11/04；維也納 11/18）
11. **球類的來向與接觸** → 球從身體後面飛來、運球手沒碰到球 → 來球從角色面對的方向（投手側）飛來、在身體前方擊中；兩手握棒，打完停在收棒姿勢看球飛走；運球時手掌要碰到球。（Free Time 11/14）
12. **接觸要用數字驗，不用目測** → 手到球 ≤2 cm、輪胎外緣到「該處路面高度」±1 cm、鞋底到踏板 ≤2 cm、球到棒面 ≤3 cm、手和道具離表面 2–5 mm、穿進去的頂點 0 個；2D 程式動畫 0–1 px。寫成檢查函式，每次渲染都印出來。（`tools/3D人物建模檢查清單.md` §5b，11/10）
13. **走路、跑步不滑腳** → 移動速度是原地踩步速度的 10 倍；模型只有原地 walk，放大像踢腿 → 用真實速度（走 1.4、跑 2.0、騎車 4.5 m/s），動作播放倍率＝移動速度 ÷ 原地踩步速度；路太長就淡出跳段（A few minutes later…），不要把人加速。沒有跑步動作就用骨頭角度程式做：大腿擺 32°、收腿時膝蓋折 107°、手肘 90° 反向擺、身體前傾、腳貼地、速度由腿長推算。（What if Ken 11/13，`output/whatif-ken-ershui/工作流程紀錄.md` #15；Free Time 11/10，`2026 REA Games/3D planet/工作流程與踩坑紀錄.md` 第五節）
14. **每個效果都要有起因（「誰讓它動」），完成要「接觸成立」** → 用計時器或正弦循環驅動，腳印、音符憑空出現，鉛筆在筆畫間瞬移，分數照時間自己加 → 鞋子離地才留腳印、落地才加分、鏈條帶動踏板、輪胎貼地線；坐下、落腳、扣安全帶、擁抱都拆成「等待 → 開始 → 接觸 → 承重 → 解除 → 結束」，接觸成立才算完成。（Free Time 線索動畫 11/10；`2026 AI ANIMATED VIDEO/deliverables/07-…v2.md` §10、`11-…v3.1.md` §6）
15. **常見手勢的正確做法** → 拍手變成手背相撞、揮手整隻手臂等速甩、指東西時眼睛看別處 → 拍手掌心相對、用掌面接觸（放大連續格看「張開／靠近／接觸／分開」）；揮手先抬手臂，再用手腕或前臂小幅擺，最後收回；指東西時眼睛和手指同一個目標；擁抱要面對面雙手環抱（並肩搭肩不算），手臂從肩膀連續畫到對方背上（上臂沿身側 → 手肘在腰高 → 前臂環過腰），兩人的頭不重疊、手在對方臉的下方。（11 號規格書 §6 10/01；感恩節 35 句 v4 11/04，`2026 Thanksgiving/rdq/RDQ-spec-thankful35-fixes2-20261104.md`）
16. **說話時身體不上下彈** → 說話時上下擺動、每格縮放、擠壓伸展，老師說「不自然的跳動」（10/30 影片 2）；Lynn 說話時整個人上下彈被退（11/16 感恩卡）→ 站著說話只留約 3 px 的慢呼吸（`breathe`，腳不離地）；只有跳、跑、歡呼才用 `bob`，歡呼只平滑跳一次；換姿勢交叉淡化 0.25 秒。**系列例外（老師 11/20 決定）：What if 系列（whatif-situation-video）保留「問的人說話時上下輕彈」**；其他片仍不彈。（記憶 sci-fi-teachers-project、thankful-card-teacher-feedback）
17. **3D 鏡頭不拍背影、大頭髮不擋臉** → 拍到背影；Q 版大頭髮角色的頭髮擋住臉，6 鏡重渲 → 鏡頭放在主角右前方 3/4、主角站畫面左 1/3；大頭髮角色先做 8 方向測試找出臉的方向（FACECAM／AZCAM）再定鏡頭；人物間距至少 3 cm；跟拍的立體字放主角前方；特寫和背景之間留「鏡頭通道」（不要種樹）。（What if Ken 11/13；水鈴版 11/15，`output/whatif-shuiling-freetime/HANDOFF.md`；感恩節 A7 11/07，總覽 A7）

## 2. 坐姿與站立貼地（11/20 英國片兩次退件）

1. 坐著時**大腿平放、蓋住椅墊**，小腿從椅面前方垂下、腳踩地。絕不能看起來「站在椅子後面」或「雙腿穿過椅墊」。
2. **椅面高度＝膝蓋高度 − 大腿網格厚度**（Q 版約 5–6 mm，從變形後的網格量：`hands.seat_under()`），人壓進椅墊約 1 mm。不要沿用模型原本的椅子高度（照手肘放大書桌後，椅面幾乎到站姿臀高）。
3. 椅子前緣在膝蓋後面約 2.5 mm；屁股和椅背之間留空隙。
4. **檢查圖固定加兩個腿部鏡頭**：側面座高、前方低角度。正面看時桌面會擋住大腿，看不出來。
5. **大頭卡通角色坐在書桌前，胸口比桌面低、手看不到** → 椅子加坐墊，讓桌面落在胸口高度、手放在胸口高度才看得到（和 1.7 同一個原則）。（Stand Out Fit In 3D 11/05，總覽 A6）
6. **量坐姿和貼地時排除裙子、披風** → 裙子頂點綁在 hips 骨頭上會往下垂，誤報「屁股陷進椅子 9 cm」→ 量測排除垂下的網格，裙子另外量。（水鈴 11/10，`2026 REA Games/3D planet/工作流程與踩坑紀錄.md`）
7. **3D 地面不是 z=0** → 地景底板厚 1.2 cm，人站 z=0 小腿陷進草地；人穿過桌子 → 用 `board()` 登記底板，人物 z 自動取 `ground_z(x,y)`；桌子用 `obstacle()` 登記；check 模式印出腳底離地 mm 和撞到什麼（誤差 ≤1 mm）。（感恩節課堂版 v3 11/07–08，`2026 Thanksgiving/classroom-tabletop/HANDOFF.md`）
8. **2D 人物不懸浮** → Lynn 腳底落在遠山上、站在樹幹前（那裡草地低），看起來浮在草地上（11/16 退件）→ 換新背景或新站位前，先疊格線量地面高度（`check/v2/_ground.jpg`）再定腳底 y；腳下影子加深；輸出前交一張「站立畫面」檢查圖。（感恩卡 v2 11/16，`2026 Thanksgiving/thankful card/film-project/HANDOFF.md`）

## 3. 3D 模型（Tripo／Mixamo）

1. 人物：65 根骨頭、兩手手指有權重、**手張開**（握拳不能用）、T／A 字站姿；做完用 `check_glb.py` 檢查。
2. **Tripo 家具常黏在一起**（椅背穿過桌面、椅子塞在桌下）：先畫頂點剖面圖（側面＋正面）確認結構。黏住就把模型的椅子整個刪掉、改用程式做椅子，不要硬切（切了會留碎片或撕破桌面）。
3. 模型自帶多餘的東西（托盤上的筷子等）用 bmesh 依座標刪，看圖確認沒破洞。
4. **下載抓檔**：Chrome 會在之後把早先所有的 `.tmp` 一起改名成 `tripo_convert_*.glb`，抓到舊檔 → 每次抓完用三角面數對 Tripo 頁面上的數字；「標記已看過」（`grab_glb.py --mark`）**一定在按 Export 之前跑**，之後才跑會把剛下載好的檔也標成看過。（11/20 取代 11/07「只抓最新那個」）
5. 一批可以同時送出多個生成；卡在 Generating 超過 35 分鐘先問老師（約 1 小時自動退點）。每筆點數馬上記帳本。
6. **生 3D 前先把參考圖畫對** → 雙手捧東西、手貼身體，自動綁骨後走路頭髮歪掉；透空走廊、曲面陽台做出一片皺紙；模型上的字拼錯、鏡像 → 人物：正面全身 A 字站姿、手張開不拿東西（道具掛腰上）、白底；同一批用同一段材質描述（例如「毛氈＋木頭玩具」）；建築參考圖重畫成「實心」；招牌一律用英文佔位字，正確文字之後用程式疊。（水鈴、二水國中 10/25，`2026 REA Games/3D planet/工作流程與踩坑紀錄.md`；感恩節 11/07，總覽 A7）
7. **面數過高拖垮渲染** → Tripo 首頁生成的腳踏車有 190 萬面（工作區生成約 2.8 萬）→ 用工作區生成；GLB 超過 20 MB 或超過 15 萬面，先 `predecimate.py` 簡化到約 12 萬面另存（原檔放 `props-orig/`），渲染效率見 5.7。（影片 8 11/09，記憶 colab-tabletop-render-efficiency）
8. **擺姿勢用「骨頭指向」，不直接轉 Euler** → Mixamo 左右手臂的旋轉軸不一樣（右手 z 是上下、左手 x 是上下），手臂常擺錯 → 用 `Char._aim`（人物座標 -Y 前、+Z 上、-X 是他的右邊），先用 `src/pose_probe.py` 出一張姿勢測試總表。（感恩節 11/07，總覽 A7）
9. **Mixamo 重定向四個坑** → 靜止姿勢不是 T-pose，右手卡在臉旁；抄手指會扭曲；自帶 idle 有 scale 關鍵格，手指炸成巨大面片；拳頭手 → 重定向前先把每根骨頭轉成 T-pose 方向（`retarget.gd _build_corr`）；不抄手指，用固定 grip 彎曲值；臀部位移照臀高比例縮放；每格骨頭 scale 設回 1 並打關鍵格；拳頭手用 `make_openhand.py` 在 T-pose 座標系鏡射好手（不用 rest space、不做 local 鏡射），輸出 `<char>_openhand.glb`，原檔不動。（Free Time 11/09–14，`output/whatif-ken-freetime/HANDOFF.md`；記憶 3d-character-model-checklist 11/10）
10. **角色變成粉紅金屬、地上有白方塊反光** → 外部貼圖沒一起上傳、金屬度高 → basecolor／normal／rm 三張貼圖和 GLB 一起上傳；材質 metallic 0、roughness 0.7；門口燈設 `visible_glossy=False`。（What if Ken 11/13，`output/whatif-ken-ershui/HANDOFF.md`）
11. **模型上的字拼錯、有品牌字** → 用 `PLATE` 色板蓋住，再由程式疊正確英文；只顯示目標招牌；蓋板大到改變建築外觀時，先給老師看改前／改後（老師偏好原貌就不蓋）；不出現連鎖品牌名稱。（What if Ken 11/13；影片 9 11/18；3D planet 11/12–13）

## 4. Blender 程式

1. **用座標切／改模型前一定先 `bpy.context.view_layer.update()`**：剛放大／移動的物件，`matrix_world` 還是舊的（11/20 切到未放大模型的一條細片，只抓到 310 面）。切完印出面數，和預期比對。（Three.js 同一類坑：移位後 `holder.updateMatrixWorld(true)`，總覽 A6）

3. 鏡頭太近會被 clip start 切掉，出現黑色剪影 → 換長焦距、站遠一點。
4. 量測要印出來（`DESK`、`CONTACT`、`REACH`、`LEGS`…），交檢查圖時附數字；不要用猜的家具高度，往下打光線量。

6. **`transform_apply(scale=True)` 預設連位置也套用** → 之後再設 `location` 會位移兩次（白鍵浮高蓋住黑鍵、車門跑位）→ 一律寫 `transform_apply(location=False, rotation=False, scale=True)`。（維也納 11/17，`output/hwg7-u03-vienna-cutout/HANDOFF.md`）
7. **Freestyle 描邊三個坑** → 背景模式下 `lineset.linestyle` 是 None；兩個物件拼接（方塊＋圓柱）的接縫描邊逐格忽有忽無；遠處密集粗線把亮光蓋成咖啡色 → 自己 `bpy.data.linestyles.new`；一個形狀做成單一網格（輪廓擠出），不要共面拼接；遠景線改細（3.2 → 約 1.4 px）；重渲後連抽 6–12 格放大看線條。（維也納 11/17–18）
8. **燈光換場景要重調，不照搬** → 搬別支片的燈光，樣張過曝全白；聚光燈從正上方打，臉和下巴發黑 → 桌上微縮燈降到約 1/5；戶外太陽 1.3–1.8、天空 0.55–0.7（3.0 整片白）；螢幕「只發光、底色黑」；聚光燈放斜前方，再加一盞跟著鏡頭的臉部補光；顏色以 Cycles 為準（EEVEE 偏亮，只拿來排構圖）。（問路 11/15、Free Time 11/14、What if Ken 11/13、感恩節 11/06–07）

10. **構圖自動檢查，0 問題才正式渲** → 特寫切到頭、立牌被擋或出畫、近景露出不該出現的東西 → check 模式＋`chk_report.py` 自動檢查頭頂 ≤0.92、臉糊 ≤3 px、貼地、穿桌、立牌被擋；每段設 `REFRAME`；立牌用 `autoplace_flags` 自動找位置，放不下就不放；近景露出的東西先讓它縮小消失（`HIDE_IN_CU`），不要一直換鏡位。（感恩節課堂版 11/07–08；問路 11/16）
11. **省渲染** → 一樣的畫面重渲很浪費 → 每格狀態算簽名，和前一格一樣就沿用前一張（`TL.uniq`／`TL.src`，問路少渲 38%）；只渲偶數格（12 fps 定格感＋省一半）；3D 影格以全片格號命名，只刪掉、重渲狀態有變的格；鏡頭每格只由時間決定（可以重現）；流程固定「3 格檢查圖 → 1 秒試渲 → 正式渲」。（問路 11/16、感恩節 11/07、維也納 11/18）

## 6. 合成與字幕

## 10. 配音（TTS）與語音辨識

1. **顯示文字和送 TTS 的文字分開存** → TTS 自己展開、黏音、吞字：全大寫逐字母念、Is 被吞、I'm 念成 I am、引號亂讀 → 用 `TTS_FIX`、`SYL`／`SYL_TTS` 兩份：音節用小寫、加逗號（`Is she, from`、`I'm, Raj`、`What day, is today?`、`P, E, class`），不用引號；改完讀回 dict，生成後用 whisper 全句核對。（影片 1–7 10/19–11/06，3d-teacher-lesson-video pitfalls A、H）

## 13. 音樂、音效與響度

1. **有閃避（ducking）的混音不要用 `loudnorm`** → loudnorm 是動態的，把小聲段落拉大（配樂壓 12 dB，量出來只降 5 dB；沒配音的段落反而變大聲）→ 先量整支響度，整支加同一個增益，再接 `alimiter`（一定要 `level=false`，不然峰值被推到 0 dB）；用每秒 RMS 驗證；8 秒左右的短音檔 loudnorm 也不準，混完量一次，差超過 1 dB 用 volume 補。（感恩卡 11/16；3D planet 11/12）
2. **響度目標：整片 −16 LUFS**（老師 11/20 統一；U04 −16.1、SF3 −16.4、Poe −16.6 都在這附近）；例外：朗讀跟讀版老師嫌太小聲，改 −14 LUFS、鼓 ×1.8（11/14）。growkaz 範本舊的 `loudnorm=I=-14` 已改。（各片 HANDOFF；記憶 read-aloud-videos-handoff）
3. **配樂閃避的做法**（標準見 6.4：說話時比人聲低 18 dB、無配音段 1/4）→ 說話時壓 1–4 kHz 或配樂 ×0.6，句子之間不回升；每句人聲調成同音量（可 +2 dB，`assemble.py` 的 MUSIC_DB／VOICE_DB）；沒配音的段落配樂 1/4（6.4）；道具特寫時配樂靜音；環境線索聲聽不出來時播完整原檔、配樂閃避 −12 dB。（SF3 R1 10/26；維也納 11/17；What if Ken 11/13）
4. **音效音量** → 音效太大聲（老師要求降一半）；AI 一次生整個場景時重點聲音不見 → 音效整體 −6 dB、無配音段再 −5 dB；素材先把有聲部分 RMS 調到 −20 dBFS 再設 dB；公有領域錄音音量差很多（RMS 0.013–0.08），各自正規化；重點聲音分開生成再疊（重點 −16、背景 −36）；短促打擊聲從起音點前 0.02 秒切。（感恩卡 11/16；感恩節 11/03；維也納 11/17；3D planet）
5. **Colab Music 3** → 單次最長約 100–127 秒；多加樂段標記反而多出人聲；不先正規化 −30 dB 會聽不到；輸出 44.1 kHz → 接長用人聲殘留最低的兩段純配樂交叉淡化；先正規化再設 dB；合成前轉 48 kHz。（U04 10/24；感恩節 11/03；Poe 11/11）
6. **公有領域音檔下載與授權** → 腳本下載 upload.wikimedia.org 回 429 → 不改瀏覽器 UA 硬繞；老師同意後用內建瀏覽器開 `Special:FilePath/<檔名>`；授權逐頁讀，記在 `audio/music/sources.json`（「只有美國公有領域」要告知老師）；Pixabay 頁面 ld+json 的 `contentUrl` 可直接下載。（維也納 11/17；感恩節）

## 15. 檔案操作（Google 雲端硬碟／Windows／改程式）

1. **大量檔案不放 G 槽** → 大量 PNG、AI 影格放在雲端硬碟一直同步；Godot 匯出卡在 0%（Permission denied）→ 影格、匯出、建置先放 `C:/Users/User/AppData/Local/Temp/<專案>` 或 robocopy 到 C 槽暫存，成品再複製回來；被清掉就從 mp4 重抽。（Stand Out Fit In §10 10/30；3D planet）
2. **同步中的刪除會失敗** → `Remove-Item` 整個資料夾在同步中途失敗、留下半刪狀態；萬用字元 `rm renders/check/*` 被安全檢查擋；GDrive 上的 `git index.lock` → 發布腳本直接覆蓋、不先刪；輸出到新資料夾；`index.lock` 等它自己消失，不要硬刪。（thankful-listen 11/17；問路 11/16）
3. **反斜線路徑會被吃掉** → Python 字串 `'C:\Windows\...'` 的 `\a` 變響鈴字元；經過 shell 跳脫寫進 .md 的 `G:\…\teacher-toolkit\tools` 變成 tab（11/20 各 skill 短版的 `\t` 就被吃掉）→ Python 路徑用正斜線；要寫進檔案的 Windows 路徑用 Write／Edit 或從檔案讀入，不經過 shell 的 echo／printf 跳脫；寫完讀回檢查。（3D planet；本檔 11/20 擴充時發現）
4. **用腳本改程式** → 替換刪錯一大段；heredoc 把 `\n` 變真換行、含引號會壞、長修補被截斷；註解插在 `if …:` 冒號前造成語法錯誤 → 替換前 `assert s.count(anchor) == 1`，改完一律 `ast.parse`；JS 行中註解用 `/* */`；長的修補先用 Write 寫成 .py 再執行；`cat >>` 沒給輸入會卡住。（whatif；phonics；mv-to-2d §4.2、§13；影片 6 11/05；總覽 A6、A10）
