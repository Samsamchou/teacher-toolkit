# AI 評分用量門檻 / AI scoring usage limits

- 現有可評分題目：35 題（SU 6、U01 10、U02 10、U03 9；U04 尚無題目）。
- 班級估算：26 人。
- 每題每日成功評分上限：3 次。
- 理論每日上限：`35 × 26 × 3 = 2,730` 次。
- 每日規劃門檻：3,300 次，約保留 20% 緩衝。Firebase AI Logic 目前沒有相對應的「每日要求數」硬配額，因此此值是容量與費用規劃值，不宣稱為雲端硬上限。
- 已設定 Firebase AI Logic `Generate content requests` 預設配額為每位使用者、每區域每分鐘 60 次，可容納一班同時送出評分並降低濫用風險。
- 前端會用本機與既有 Firestore 紀錄交叉檢查每題每日 3 次，成功評分後顯示本題今日剩餘次數；因學生端沒有正式登入，這層屬於防誤用，不宣稱為不可繞過的身分型配額。
- Firebase AI Logic 的 App Check 基準防護已設定為強制執行；重放攻擊防護維持監控模式，避免額外延遲與費用。
- Google Cloud 的上述「每位使用者配額」沒有提供用量指標，控制台不能直接建立要求數警示。若要建立金額型 Cloud Billing 預算警示，需先由專案擁有者指定每月預算金額與通知門檻。
