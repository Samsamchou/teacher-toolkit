# 驗證範圍 / Validation v1.0.0

本包用自製cat/dog小份教材示範讀寫2題、聽力1題，不代表正式試卷。

離線檢查項目：讀寫與聽力草稿可通過；兩者因缺正式教師驗收而在release模式被阻擋；錯誤總分、錯誤答案代號、未知卷別、未核對來源、錯誤朗讀字及重複事件會被拒絕。文件連結、技能frontmatter及公開檔案清單另檢查。

原附帶檢查器的公開版增加未知卷別防呆。未改作者個人安装版。這些是結構測試，不是獨立模型評審或教師驗收。小份示例已人工對照：cat=貓；Alex有貓；讀寫答案A/B、聽力A。

技能製作工具的quick_validate在本機因缺PyYAML無法執行，改用直接檢查frontmatter、名稱、描述、連結與Python執行測試；不冒稱官方驗證器已通過。未在同事電腦實際安裝，不宣稱所有環境皆可直接使用。

沒有執行付費製音、OCR或正式Word排版；PDF與音訊完整流程需使用者另備工具及資料。公開內容經本機路徑、常見金鑰格式及檔案類型檢查，但任何自動掃描都不是保證偵測所有秘密的方法。
