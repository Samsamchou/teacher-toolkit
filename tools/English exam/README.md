## 能做什麼

協助整理自己的教材資料夾、建立索引、整理出卷規則與考卷範本、重新讀取既有規則，以及提出含答案、來源和Bloom配分的草稿。老師仍須檢查內容與紙本，聽力需先審錄音稿再製音。

本包不含出版社教材、題庫、原校方文件、實際考卷或音檔。示例為本包另編，並非 HWG 原文。分享技能不等於取得教材使用權。未附第三方開源授權條款，不宣稱所有教材可再散布。

## 工具及限制 / Requirements and limits

需能讀写教師指定資料夾的 Codex 環境；Python 3.11+ 用於附帶離線結構檢查。PDF/OCR、Word排版、圖片及語音需環境中實際可用的工具。RDQ未安裝時仍可用技能內的需求確認程序，不自動安裝其他技能。語音預設 Gemini 優先、OpenAI 備援，但須另確認可用工具、帳號、當次費用上限及外傳內容。本包沒有付費API執行器，下載不會自動扣製音費。

五年級0.9倍速是本技能預設，可由使用教師明確調整；不是校方或全國通用規定。四、六年級另確認。原作者私人技能與教材庫未被此公開版覆寫。
