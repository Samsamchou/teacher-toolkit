# 命題與紙本

確認學校、學年度、學期、年級、版本/冊次、期中或期末、單元、已教內容、聽力或讀寫、總分、題型題數、時間、補充字、Bloom配分、版面、交付及驗收。每題保存來源ID/頁碼、題幹、選項、答案、分數、Bloom理由；新編例句清楚標示。

記憶是提取或辨認；理解是理解意義；應用是在情境運用所學；分析是區分資訊及關係。不以字數或題型名稱直接決定層次，不把Bloom層次等同實際答對率。補充字只納入教師確認清單。

發音例字不跨題重複考同一字；同題規定重讀是例外，一般功能詞可重複。不要用同音字拼法作無法從聲音區別的選項。每題充分資訊、唯一可辯護答案；開放題列合理替代答案及部分給分。

動作圖句避免含糊否定，但不全面禁止否定句。課表題分清問誰、哪天、科目；on Monday不等於今天是Monday。對話避免每題同樣結尾。

讀寫核對拼字、大小寫、標點給分、重組句替代順序、填空變體、閱讀文內證據及跨題洩答。

題型與字型依教師實際範本，不搬入作者學校規範。可選字型特例a/J用Comic Relief、t用Arial須教師採用才套；核查實際字型及PDF顯示。A4雙欄一頁是可選版面，不得壓縮到影響作答。黑白圖表清楚分姓名、星期、科目。

草稿先交學生題目、答案/評分與來源/Bloom表，聽力另交稿。確認後DOCX及PDF逐頁檢查漏字、跨頁、露答、圖片語意、配分及列印清晰度。修改答案須同步相關選項、教師卷及音訊稿。
