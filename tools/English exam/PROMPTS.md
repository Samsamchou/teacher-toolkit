# 操作提示詞 / Prompt handout v1.0.0

【】內換成自己的內容。需先安裝技能；AI必須能讀寫指定資料夾。所有「請保存」只適用於使用者指定的工作區，不覆寫原稿。

## 1 建教材資料夾

```text
請使用 $english-exam。教材位置：【路徑】；整理結果另存：【路徑】。年級／出版社／冊別：【內容】。
先盤點檔案、檔型與數量，保留原檔不更名不移動。依課本、習作、備課資料、題庫、音訊、考卷範本建立Markdown索引及總目錄。先告訴我可讀與不可讀的部分，再依已確認範圍整理。逐項記錄來源、單元、頁碼及狀態；不要把OCR成功或檔名對上當作內容已驗收。補充字與課本字分開。音檔對應不明時列待確認，不猜配對。不上傳、不呼叫付費API。
```

## 2 保存命題原則及範例考卷

```text
請使用 $english-exam。原命題原則：【檔案】；範例考卷：【檔案】；整理位置：【路徑】。
讀取後另存rules.md及templates.md，保留原檔。rules.md分開校方原規範、教師補充及這次考卷設定。templates.md記錄題型、配分、頁數、字型、欄位、圖片與作答空間，附來源頁碼。衝突或看不清楚的內容列待確認。另存START_HERE.md，連結教材總目錄、rules.md及templates.md，讓下次可重新讀取。先給我摘要核對，不出題或製音。
```

## 3 下次重新叫用

```text
請使用 $english-exam。請讀【整理位置】的START_HERE.md，再實際開啟它連結的教材總目錄、rules.md及templates.md。列出讀到的檔案與本次會沿用的規則；找不到或互相衝突的部分先告訴我。不只依賴舊聊天記憶，暫不出題。
```
