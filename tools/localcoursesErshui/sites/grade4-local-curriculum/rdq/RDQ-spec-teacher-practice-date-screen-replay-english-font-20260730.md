# RDQ 需求規格：教師練習日期、作答重播與英文字級

## 一句話任務
修正教師後台的練習日期分類，加入無聲作答影片與完整畫面重建備援，並放大全站英文。

## 已確認
- 教師後台日期改為學生按下「開始練習」當下的**臺灣日期**，不再以學生選擇的 `travelDate` 搭車日期篩選。
- 新增可信的 `practiceStartedAt` 與 `practiceDateTaipei`，以 Firebase 伺服器時間產生；`travelDate` 獨立保留並明確標示「搭車日期」。
- 教師後台日期、紀錄卡、詳細資料與 CSV 都顯示「練習日期」；詳細資料另外顯示搭車日期。
- 既有紀錄依 `createdAt` 伺服器時間換算 Asia/Taipei 日期並回填，改版前資料仍可依練習日查詢。
- 支援裝置在學生按下開始後，要求主動選擇**目前瀏覽器分頁**，以 `getDisplayMedia` 和 `MediaRecorder` 建立無聲影片；不得錄取麥克風或系統音訊。
- 錄影建議 720p、低幀率、單檔上限 80MB，保存於受教師權限保護的 Firebase Storage，沿用一年保存與到期清理。
- 學生拒絕授權或裝置不支援時，不阻擋練習，改用逐步畫面重建動畫。
- 教師後台有錄影時優先顯示可播放、暫停與跳轉的影片播放器；無錄影時顯示逐步畫面重建動畫；原始事件文字清單預設收合。
- 畫面重建必須重現七步驟的實際頁面、選項、選取狀態、答錯提示、核取與換頁，不再只顯示火車進度條。
- 錄影前用圖解提示學生只選目前分頁，避免錄入其他分頁、通知或個人資料；瀏覽器仍保留最終選擇權。
- 全站英文標題至少放大為目前的 1.3 倍；英文按鈕、欄位與說明至少 18px，主要句型與生活用語為 20–24px。
- 英文字級調整涵蓋首頁、四單元、購票七步驟、成功頁、教師登入與教師後台，並維持桌機、iPad及手機無截斷或水平溢位。

## 待確認假設
- 教師後台預設先顯示最近的練習日期，日期選擇器只查 `practiceDateTaipei`；跨午夜完成仍歸入開始練習當日。
- 影片格式依瀏覽器選擇 WebM／MP4 相容格式，後台以 HTML5 播放器播放，不另行轉檔。
- 舊紀錄若缺少可用的伺服器 `createdAt`，標示「日期待確認」而不使用學生選擇的搭車日期代替。

## 已採納建議
- 伺服器產生練習日期；回填既有紀錄；720p低幀率與一年期限；錄影前隱私引導；重建完整操作畫面。

## 本次不納入
- 錄製聲音、攝影機或其他應用程式；繞過瀏覽器錄影授權；永久保存影片；將影片公開給學生或未登入訪客。

## 一段式需求規格
在 **C:\firebase-deploy\在地課程\sites\grade4-local-curriculum** 更新並重新部署 Firebase 網站：由後端以 Firebase 伺服器時間建立 `practiceStartedAt` 與 Asia/Taipei 的 `practiceDateTaipei`，教師後台、紀錄清單、日期篩選與 CSV 全部按開始練習日期查詢，同時分開保留及顯示 `travelDate` 搭車日期，並回填既有紀錄；學生開始練習時，在支援裝置上以明確圖解引導其授權分享目前瀏覽器分頁，使用 `getDisplayMedia({audio:false})` 與 `MediaRecorder` 產生無聲、約 720p、低幀率且不超過 80MB 的影片，上傳至教師限定的 Firebase Storage 並保存一年，若拒絕或不支援則以事件資料重建七步驟的頁面、選項、錯誤、勾選與切換畫面；教師後台有影片時優先提供播放器，否則播放畫面重建動畫，事件文字清單預設收合；全站英文標題放大至少 1.3 倍，英文按鈕與欄位至少 18px，主要英語句型為 20–24px，桌機、iPad及手機均維持清楚、無截斷及無水平溢位。
