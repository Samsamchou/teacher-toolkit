# RDQ 需求規格卡｜火車線上購票網站 Firebase 改版
狀態：草案，等待使用者確認｜日期：2026-07-29｜RDQ：Full（2 輪、8 題）

## 一、目標與對象
- 將四年級「坐火車趣集集」的模擬購票活動改成吸引兒童的互動網站，部署至 Firebase 專案 `hwg8-u01-listen-and-speak`。
- 主要使用者為二水國小四年級學生（iPad 操作）；教師可在後台依日期與學號查看歷程。
- 本站是「真實資料的教學練習」，不連接臺鐵訂票、不產生真實交易。

## 二、學生端範圍
- 首頁名稱：「火車線上購票網站－Buy Train Tickets Online」，輸入五碼學號（例：40100）後開始。
- 視覺採臺鐵票務藍、暖橘、奶油白與 3D 鐵道冒險插圖；保留清楚的大按鈕、進度列與 iPad 觸控尺寸。
- 7 個過關步驟：輸入學號、選日期與搭車時段、選起訖站、選車次、核對摘要、確認車票、完成。
- 每步正確時播放 “You’re right!” 音效及短慶祝動畫；錯誤時提供可理解的提示，不揭露答案。
- 日期使用網站開啟日所對應的最近未來週五、週六、週日；若本週五已過則順延下一週，並以 Asia/Taipei 驗證。
- 日期選定後，學生以「開始時間／結束時間」選擇預計到二水車站搭車的時段（例：09:00–12:00）；開始時間必須早於結束時間。
- 出發站固定「二水」；抵達站由學生選「集集／水里／車埕」，後續時刻、行車時間、摘要及票面同步更新。
- 日期選擇器及起訖站欄位的資訊層級參照使用者附件；不複製臺鐵商標或造成官方網站誤認。

## 三、真實車次資料
- 禁止「模擬車次 A／B／C」；候選車次使用附件列出的 2703、2705、2707、2711、2713、2715、2717、2721、2723、2725、2727。
- 車埕班次基準：2703 05:54–06:46、2705 08:00–08:49、2707 09:15–10:08、2711 10:40–11:29、2713 11:57–12:49、2715 13:20–14:09、2717 14:40–15:29、2721 16:05–16:54、2723 17:28–18:18、2725 18:52–19:40、2727 20:20–21:09。
- 顯示正式車種與車次（區間／區間快＋編號）、出發、抵達、行駛時間；集集與水里的抵達時間須逐班由臺鐵官方資料核對，不以固定分鐘數推算。
- 車次頁以二水站「發車時間」篩選，範圍包含開始與結束端點；例如選擇 09:00–12:00 時，顯示 2707（09:15）、2711（10:40）、2713（11:57），不顯示範圍外車次。
- 若所選時段沒有班次，顯示「這個時段沒有合適的火車，請重新選擇時間」，並提供返回修改時段的按鈕，不自動加入假車次。
- 教材保存「資料來源＋查詢日期」；班次若日後改點，更新中央資料檔即可，不散落硬編碼。
- 官方依據：https://www.railway.gov.tw/tra-tip-web/tip/tip001/tip112/querybytime

## 四、教師後台與保存
- 教師後台左欄顯示日期與學號；右欄顯示完成狀態、分數、各步時間、操作事件、7 張過關畫面合成 PDF，以及可用時的無聲畫面錄影。
- 學生以 Firebase Anonymous Auth 建立工作階段，直接依 Security Rules 寫入 Firestore／Storage；教師帳號以安全權限讀取。
- 資料採新版命名空間（如 `tickets-v2`），不混用既有紀錄；保存一年後自動刪除 Firestore 紀錄、PDF、影像與影片。
- 啟用 App Check、最小權限規則、檔案類型／大小限制、Asia/Taipei 日期的前後端雙重檢核，並以 Emulator 測試允許與拒絕案例。

## 五、部署與限制
- 使用 Firebase 專案的預設 Hosting Site，使用者已接受部署會覆蓋該 Site 現有內容的風險；部署前仍須先列出目前 Site 與建立可回復版本。
- 使用者稍後以該 Firebase 專案擁有者 Google 帳號重新授權 Firebase CLI；未取得專案權限前不得聲稱已部署。
- iPad 瀏覽器不保證可由網頁自動擷取整段螢幕錄影；實作時先檢測能力並徵求螢幕分享權限，無法使用時仍完整保存事件時間線與 7 頁 PDF，後台清楚標記「此裝置未支援錄影」。

## 六、本次不包含
- 真實訂位、付款、身分證字號、臺鐵會員登入、即時臺鐵 API 串接、回程票與票價交易。
- 未經核對即猜測集集／水里到站時間，或使用假車次補位。

## 七、驗收條件
1. iPad 尺寸下可完成「二水→集集／水里／車埕」任一路徑，日期僅有正確週末三日，可設定有效搭車時段，且全程無模擬車次字樣。
2. 選擇 09:00–12:00 時只出現 2707、2711、2713；三個目的地各抽查至少兩班，車次、出發與抵達時間和保存的臺鐵官方來源一致，摘要與完成票面同步。
3. 匿名學生只能寫自己的工作階段；未授權者不能讀教師資料，規則測試涵蓋跨學生存取、錯誤日期與超規檔案。
4. 教師後台可依日期／學號開啟完整紀錄與 7 頁 PDF；一年期清除規則可由測試資料證明。
