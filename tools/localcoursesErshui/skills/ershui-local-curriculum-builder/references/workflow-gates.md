# 工作關卡

## 0. 判斷目前位置

先讀工作索引、交接、工作紀錄、相關 confirmed RDQ 及現有成果。列出已完成、目前關卡、下一個必須由教師確認的項目。已通過的關卡只做必要稽核，不重新產製。

## 1. 單元 RDQ

每個正式單元都要有完整 RDQ。優先釐清：

- 正式年級、學期、單元名稱、週次與節數。
- 原活動哪些保留、替換或新增，以及教師理由。
- 各節可見成果、評量證據與英語功能。
- 教材類型、是否需要網站、不可接受結果與驗收方式。

將規格卡存入專案 `rdq/`，使用 `draft → confirmed → archived`。教師明確確認後才進入來源追溯。

## 2. 正式課程與頁碼確認

先定位該年級、該學期、正式課名「在地課程」的原始頁面及抽取文字。記錄檔名、PDF 頁碼、文字行號與原文重點；不要混入同頁其他正式課名，也不要從既有教案反推原課程。

## 3. 來源追溯與設計決定

追溯鏈至少包含：

`原始來源 → 教師補充／替換理由 → 設計決定 → 教學活動 → 評量證據`

每項決定標示為原課程保留、教師補充、教學替換、合理拆分、英語融入或條件式延伸。教師未確認的項目保持待確認，不寫成既定事實。

## 4. 全單元節次骨架

先分配每節的在地核心、活動主線、主要評量證據與可見產出，再選支援活動的中英字詞及句型。骨架須保留原單元活動主軸，不因英語教材方便而改造成一般英語課。

骨架確認後才能展開逐節詳案。

## 5. 逐節循環

每一節依下列順序，兩個教師確認關卡不可合併：

1. 詳案樣稿：課前教材、核心英語、四階段、教師操作、學生材料與行動、時間、互動、可見成果、評量證據。四階段「主要活動標題」的第一層須能直接供課程審查，標題本身包含核心內容、學生動作與教學目標；第二層再用一至兩句具體描述。詳案列出的每一項手作教材都須附內容與操作草圖，標出尺寸、人數、欄位／題目、圖像鷹架、操作順序、學生填答處及教師答案；此時只說明活動，不製作正式教材。
2. **教師確認詳案。**
3. 教材草稿：列教材清冊、內容、來源、提示詞／題目／版面規格與 QA 方法；需要角色或插畫時，先用同一主體提供風格比較樣張，教師選定後才製作正式美術版。教材草稿同步規劃學生版及教師解答版，不直接正式生成。
4. **教師確認教材草稿。**
5. 製作與 QA：建立可重建工具，執行內容、結構與視覺驗證，保留 QA 紀錄。
6. 更新工作索引，才進入下一節。

正式手作教材若採 ImageGen 視覺母版，預設仍須先交一組代表性的學生版／教師答案版並等待教師確認，再批次製作其餘頁面。只有當次 `status: confirmed` RDQ 明確記錄必要的代表組確認已完成，且授權同一批次不中斷完成時，才可免除再次暫停；此例外不得沿用至其他單元或未來批次。詳案、教材內容或一般 RDQ 確認本身不會自動通過這個視覺樣稿關卡。

若接續中的單元已完成前一節，第一個新產出就是下一節詳案；「第一節詳案樣稿」是一般關卡名稱，不是要求重做第 1 節。

## 6. 關卡回報

每次停在教師確認時，回報：

- 本次新增與未修改的基線。
- 可點開的檔案路徑。
- 來源、頁碼與尚未確認假設。
- 預計下一步，但不先執行。
