# 來源與課綱

## 來源優先序

1. 該年級校定課程 PDF 中正式名稱為「在地課程」的表格列。
2. 同一 PDF 的抽取文字／表格，只作定位與逐字查核。
3. 三、四年級英語部定及彈性課程計畫。
4. 英語、社會、綜合活動正式課綱與《臺北市國民小學英語聽說評量手冊》。
5. 官方機關、場館、鐵路或地方政府資料；需要時再用可信交叉來源。
6. 既有教案只能作基線或設計參考，不能取代正式課程原文。

專案現有來源入口包括 `3年級 校定課程.pdf`、`4年級 校定課程.pdf`、四份三／四年級英語計畫、三份領域課綱及 `_course_source_md/` 的可搜尋文字。

## 正式課名與頁碼查核

- 先找年級、學期與週次，再確認同一列的正式課名恰為「在地課程」。
- 記錄 PDF 顯示頁碼和抽取文字行號；兩者不一致時同時保留並解釋。
- 摘錄原單元名稱、節數、目標、活動、評量與教材。未寫在原文的現地踏查或其他背景只能標為教師補充。
- 不混入〈繽紛校園（一）〉等其他課程，即使週次相鄰或活動相似。

## 英語融入

先完成在地活動，再從三、四年級英語計畫選擇能直接支援觀察、描述、提問、回答或介紹的語言。不要因同期進度或英語單元主題改變在地課程。

- 專有詞可作看圖辨識與口說標籤，不必要求拼寫。
- 評量以在地知識、觀察與來源證據為主，英語可理解表現為輔。
- 只採用活動實際需要的單數、複數、位置或描述句型，不另開文法教學。

## 課綱寫法

- 分列「學習表現」與「學習內容」。
- 保留完整代碼及官方敘述，不只列代碼或自行縮寫。
- 每個對應都要能回指到詳案中的活動與評量證據；無活動證據的代碼不列。
- 單元層級可集中列出共同課綱，逐節詳案仍要能看出實際對應。

## 來源保存

不修改 PDF、原 Word、抽取文字及已確認追溯文件。新解析或更正另存可比較版本，附來源路徑、日期及必要的頁碼／行號。
