# 〈扇形車庫〉2節教案骨架（教師確認版）

> 狀態：教師已於2026-08-25確認。依固定關卡先展開第1節四階段詳案樣稿；確認後再完成第2節。

## 一、單元固定範圍

- 對象：二水國小四年級。
- 期程：第1–2週，每週1節，共2節。
- 原始單元：〈扇形車庫〉。
- 原始目標：能說出扇形車庫的由來；能說出扇形車庫的構成要件。
- 原始活動：影片觀賞、分組討論與提問回答、書寫學習單。
- 原始評量：分組上台發表與問答、學習單。
- 替換決定：因交通、安全、時間及經費因素，取消原規劃的實地踏查，改在校內以影片及經教師確認的替代材料完成觀察。踏查為教師補充的原規劃，並非正式課程文字所載；決定與理由均已由教師確認。

## 二、活動先行後的2節骨架

### 第1節｜影片觀賞：找到扇形車庫的關鍵構件

| 項目 | 骨架內容 |
|---|---|
| 原始來源 | 「影片觀賞」＋「能說出構成要件」 |
| 本節在地核心 | 透過影片與必要的官方照片／俯視簡圖，觀察扇形車庫外形，找出火車、軌道、轉車台與車庫等主要構件 |
| 活動主線 | 觀察局部圖或影片預測 → 觀看教師選定片段 → 暫停找證據 → 小組配置構件 → 分享看見的證據 |
| 替換處理 | 不實地前往扇形車庫；以原課程指定影片為基本觀察來源，官方照片與俯視簡圖待教師確認後補足現地空間觀察 |
| 設計界線 | 不在骨架階段固定影片秒數、分組角色、圖卡數或四階段時間；照片與俯視圖須經教師確認後才列為正式教材 |
| 在地評量證據（主） | 能指出至少3項主要構件；能用中文說出至少1項影片或圖片證據；小組配置結果合理 |
| 英語功能證據（輔） | 看圖能口說至少2個核心詞；能依畫面中的單數／複數構件，完成至少1次 What’s this/that? 或 What are these/those? 問答 |
| 本節可見產出 | 構件辨識／配置紀錄＋個人觀察證據記錄 |

### 第2節｜討論與學習單：說明由來、構件與功能

| 項目 | 骨架內容 |
|---|---|
| 原始來源 | 「能說出由來／構成要件」＋「分組討論並提問回答」＋「書寫學習單」＋「上台發表」 |
| 本節在地核心 | 使用第1節證據整理「為什麼興建、有哪些構件、構件如何協助火車頭調度／停放／維修」 |
| 活動主線 | 回看第1節證據 → 分組整理由來—構件—功能 → 個人完成學習單 → 小組短講 → 同儕提問回答 |
| 設計界線 | 暫保留30秒導覽概念，但秒數、分工與英文比重待教師確認；顏色句型只在保留四色圖例時使用 |
| 在地評量證據（主） | 學習單能說明由來與主要構件；至少1項功能有影片／官方圖文證據；小組能回答內容問題 |
| 英語功能證據（輔） | 能使用核心詞指認構件；能完成至少1組指認問答，並視俯視圖完成 Where’s the turntable? 位置問答 |
| 本節可見產出 | 個人學習單＋小組短講／問答紀錄 |

## 三、活動完成後才配入的英語

### 主要句型

| 語言 | 用途 | 三／四年級英語計畫來源 | 是否採用 |
|---|---|---|---|
| What’s this? It’s a ___. | 指認近處圖卡、學習單或構件卡 | 三年級部定計畫 Lesson 1；TSV第42行 | 建議兩節共用 |
| What’s that? It’s a ___. | 指認遠處投影或海報 | 三年級部定計畫 Lesson 2活動中含 What’s this/that?；TSV第43行 | 建議兩節共用 |
| What color is it? It’s ___. | 讀取四色圖例，不作顏色主題教學 | 三年級部定計畫 Lesson 2；TSV第44行 | 條件式，待教師決定D-07 |
| What are these/those? They’re tracks. | 指認多條放射狀軌道，區分單一構件與複數軌道 | 四年級部定計畫 T1 Lesson 1；TSV第43–44行 | 建議第1節觀察全景時使用 |
| Where’s the turntable? It’s in the middle. | 指認中央轉車台的位置，連結構件配置與功能 | 四年級部定計畫 T1 Lesson 2；TSV第45行；`in the middle`為本單元所需位置語 | 建議第2節使用俯視簡圖時使用 |

四年級句型採「功能到才使用」：看到多條軌道才使用複數問答，討論中央轉車台才使用位置問答；不要求同一位學生在一次評量中使用全部句型，也不另教完整單複數或介係詞文法。

### 單元重點中英雙語字詞

| 中文 | 英文 | 在活動中的用途 | 學習要求 |
|---|---|---|---|
| 火車 | train | 指認影片或圖片中的火車 | 看圖辨識、聽說，不要求拼寫 |
| 軌道 | track | 指認放射狀軌道及火車行進路徑 | 看圖辨識、聽說，不要求拼寫 |
| 轉車台 | turntable | 指認中央轉向構件 | 看圖辨識、聽說，不要求拼寫 |
| 扇形車庫 | roundhouse | 指認整體建築／車庫區 | 看圖辨識、聽說，不要求拼寫 |
| 火車頭 | locomotive | 說明被轉向、停放或維修的對象 | 延伸口說標籤，不要求全班獨立說寫 |

說明：三年級句型支援單數構件指認；四年級句型補充多條軌道及中央位置關係。人物、職業等無直接用途的句型不納入。四年級彈性計畫中的小組觀察、討論、製作與發表方式可作活動方法參考，但不能改變原在地課程主軸。
