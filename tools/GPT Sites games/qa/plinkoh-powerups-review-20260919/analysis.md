# Plink-oh! Power-up 再次檢視 / Power-up reinspection

日期：2026-09-19。範圍：需求分析與RDQ準備，尚未修改遊戲。

## 直接確認
- 從同一原片重新擷取22張畫面：68–80秒、128–136秒；來源SHA-256與先前一致。
- 72–75秒，滑鼠停在Power-ups，提示為「Choose which ones and the probability of each」。這能確認原版支援選擇種類與各自出現機率。
- 這兩段設定操作沒有打開Power-ups子選單，也沒有顯示具名卡牌、卡牌清單或選卡流程。不能從ON字樣推斷原版種類。
- Spikes、Low Scores是另外列出的設定項，不能直接等同某張Power-up卡。普通柱、粉柱、綠柱外觀也不足以證明卡牌清單。
- 原錄影沒有Winner結局。現行實作結局只有簡單星星透明度動畫，沒有專用勝利聲；本次使用者已明確要求補上5秒音效與Winner勝利動畫。

## 本專案卡牌提案，非原版種類
1. Double Pegs：本次碰柱得分乘2，底槽分不變。
2. Double Slot：本次最終底槽分乘2，碰柱分不變。
3. Bonus 10：本次結算額外加10分。
4. Second Chance：連續落兩球，取較高的一次總分，只入帳一次。
5. Big Ball：本次球半徑變成1.4倍，實際碰撞隨之改變，不保證比較高分。
6. Safe Landing：本次總得分至少20分。

待RDQ決定：卡池採全部6種或前4種、每次提供卡牌方式、每組可用次數。
沿用已確認條件：老師自由選組、每組每回合一次、2–15組、預設6回合、無题目答案、遊戲純英文及管理區英中雙語、本機保存。
建議選卡及隨機結果一併保存，避免重新整理洗牌；同一輪只套用一張卡，不疊加；大圖示卡面用SVG/CSS實作，無需付費生圖。
勝利效果建議：5秒原創慶祝聲（短號角式旋律與掌聲層次）、皇冠進場、贏家球躍動及彩紙，結束後停在靜態排名。平手共同慶祝；靜音、跳過與退出停止聲音。
