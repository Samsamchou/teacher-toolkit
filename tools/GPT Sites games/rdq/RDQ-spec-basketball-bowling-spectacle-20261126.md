# RDQ 需求規格：Animal Basketball／Bowling Game 華麗升級

## 一句話任務

## 已確認
- 對象與場合：國小 3–6 年級，教室大螢幕（Big Screen）；選好選項後才播放動畫。
- 動畫（1A）：球道、球瓶、籃框、球改為真正的 3D 與物理碰撞，鏡頭可運動。
- 音效（2A）：改用真實錄音的免費授權音效與新背景音樂，不花錢，保留授權與來源紀錄。
- 長度（3C）：一般球 3–4 秒；三分球（含 4 分 Long shot）、全倒（Strike）、功能卡 6–8 秒並加慢動作重播。
- 範圍（4A）：首頁兩款獨立遊戲、Unscramble 答對獎勵、Phonics 接入的版本全部換新版。
- 不改：規則、計分、機率、功能卡效果、組數與回合、存檔恢復、既有紀錄。
- 參考影片：`參考遊戲/bowling.mp4`、`參考遊戲/Video_260913091733_免費導出.mp4`。

## 待確認假設
