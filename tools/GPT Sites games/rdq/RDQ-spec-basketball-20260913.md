# RDQ 需求規格：動物投籃 / Animal Basketball
## 一句話任務
依指定影片完整重現投籃遊戲的可見畫面、操作、動畫與聲音體驗，移除問答並加入六種可愛動物，整合既有 Classroom Club。
## 已確認
- 教師回答：1A、2A、3A；四項建議全部採納。
- **2–6 組**，每組可重新命名；每回合由老師點選答對組別的動物開始投籃，次序不固定；每組投籃或跳過一次後即標示本回合已完成，不能重複選；全部組完成才進入下一回合。
- **1–10 回合，預設 6 回合**；每回合所有組各輪到一次，結束可追加回合。
- 六種可選角色：**貓、狗、兔子、熊貓、狐狸、企鵝**；可愛粗白邊貼紙風格，包含持球、出手、命中慶祝、失手反應。
- 教師最新指定：角色圖片必須使用**內建 Image** 繪製，要求高品質動物角色插畫；六種角色造型完整、風格一致、表情清楚，持球與投籃動作自然，不能以 emoji 或簡易幾何圖代替。此指定取代本任務原先的 Images API 路線。
- 保留漫畫網點設定頁、夕陽街頭球場、場景裝飾、球路與結果效果、皇冠、排行榜、頒獎台、平手和彩紙、重新開始及追加回合。
- 納入 Power-up、動態命中率及影片出現的四分球；未證實規則需追查與列出差異，不可假裝已還原公式。
- 畫面顯示角色、組名與分數、目前／總回合、各分值當下命中率、音樂／音效／環境聲控制與狀態。
- 教師追加確認：每次一球；跳過不加分並回到老師選組畫面；追加回合保留分數；各組動物不重複；管理區英中雙語、遊戲純英文，支援滑鼠與觸控。
- 教師追加需求：依設定回合數維持各組比分拉鋸，到最後一回合完成後才結算勝負或平手；五回合只是例子，並非更改預設六回合。
