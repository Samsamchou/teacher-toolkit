# 東岸淨灘探索改版

使用者確認四題與四項建議後，已回覆「照這份開始」。

- 斜側面平滑跟隨鏡頭，臺灣東岸沙灘分區探索，物品自然散落。
- 手動可自由點選目前區域內可見垃圾，角色完成動作後才接受下一次點選；清完小區再前進。
- 自動每條約 25 秒，含尋找、走近、停下、彎腰、夾取、裝袋、得分；暫停不計時。
- 保留兩組六回合共十二路徑、五位等能力角色、七種事件與原計分分布。意外按進度觸發，改變拾取順序不改總分。
- 物件實際落在沙面，取消格狀排列與虛線路徑；保留大尺寸點選區。
- 海浪、微風、輕快原創背景音樂；問答降低背景聲；拾取、腳步、扣分、勝利音另行播放。
- 背景與事件音量分開控制，靜音、暫停／離開停止播放；減少動態降低鏡頭運動。
- 塑膠袋有兩個提把、袋口、半透明袋身、皺摺。單張預覽確認後才套用。
- 保留英中管理、純英文遊戲頁、畫筆、全螢幕與課堂儲存。
- 本次完成本機改版與驗證，Firebase 發布另行處理。

驗收：自由選擇與連點防重複；各路徑七事件完整、分數一致；自動約 25 秒；聲音隨階段調整；鏡頭跟隨與撿拾動畫同步。
