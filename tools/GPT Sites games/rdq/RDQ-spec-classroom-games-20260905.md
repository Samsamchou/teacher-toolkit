# 需求規格 / Confirmed specification
使用者於兩輪訪談後明確回覆「照這份開始」，修正為 Firebase 與英文主介面。
## 已確認
- 新建「上課互動遊戲大集合」首頁，第一版實作刮刮樂；教師可新增、改名、排序、隱藏遊戲連結。
- Firebase project: **gamesinclass-5d9d1**；教師使用 **6 碼通行碼** 登入，不使用 Gmail／Google 教師登入。正式部署另行授權。
- 私人跨裝置圖片庫，PNG/JPG/WebP，支援不同尺寸；初期驗收 50 張及第 51 張，無固定張數上限，受實際容量限制。
- 本專案遊戲共用圖片庫，各自保存課堂清單；課前選圖、數量、排序並確認進入遊戲。
- 一次一張大圖，教師切換；手指與滑鼠左鍵拖曳局部刮圖，保持比例、完整顯示。
- 一般與全螢幕左上角均有小圖示可展開的懸浮畫筆，具較大觸控範圍。
- 工具含手寫、直線、正方形、長方形、圓形、選色、局部橡皮擦與清除全部筆跡。
- 刮圖、註記模式分開；擦除只作用於筆跡，不改圖片或刮開進度。
- 右下角按鈕以 **8 秒** 刮開目前整張圖片；圖片庫與課堂清單可匯出匯入。
- 主要設備 Windows 電腦接觸控大螢幕，Chrome/Edge；英文主介面、卡片式首頁。
## 本次不納入
其他新遊戲、學生帳號、多人連線、計分排行、外部遊戲自動共用圖片；未授權部署或開通付費資源。
## 一段式需求規格
建立教師私人使用的 **上課互動遊戲大集合** 與刮刮樂，以 **Firebase gamesinclass-5d9d1** 為目標、伺服器驗證 **6 碼通行碼** 取得私人權限，英文為主。首頁入口可自行管理，共用圖片庫持續擴充，各遊戲保存獨立選圖及排序清單。上課一次一張原比例完整圖片，支援手指與滑鼠刮圖、左上角繪圖工具、右下角 **8 秒** 全圖揭曉；提供備份還原，先本機驗證再另行授權正式部署。
## 驗收
- [ ] 50 張不同尺寸圖片及第 51 張保存、跨裝置讀取，未授權者不能存取。
- [ ] 首頁管理、選圖、清單保存及播放順序正確。
- [ ] 滑鼠和實際觸控刮圖及畫筆可用；全螢幕及縮放不移位、不重置；揭曉耗時 6–9 秒。
- [ ] 備份還原保留图片與清單；本機、雲端與實際設備驗證分開記錄。
