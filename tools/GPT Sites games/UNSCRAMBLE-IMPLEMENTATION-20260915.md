## 教師操作

1. 在題組頁選「載入七題家人題組」；七題句子與提供的 1.png–7.png 已備妥。
2. 編輯題組：第一頁設定圖片，第二頁輸入問句與答句。可新增／刪除題目、更名與儲存。
3. 明天換班：按「複製題組」，更名、逐题換圖片後儲存，原題組不受影響。
4. 選「建立新場次」，輸入班級／活動名稱並設定 2–8 組。每個新場次有獨立 QR 與紀錄。
5. QR 可以點選放大。學生輸入同組所有學號，以空格分隔，每台平板自動分配一個組號。
6. 教師先展示圖片，再按 Next 開放該題。學生同時看圖片，把混合字卡排成兩句，按 Check answer。
7. 按 Next 切到下一張圖片時，學生立即鎖定；投影保留上一題各組紀錄。再次 Next 才開放新題。
8. 答對後鎖定；最多五次，五次用完等待教師說明，不公布標準答案。未完成題不填零分，顯示未作答。
9. 後台可查看各題每次作答、切換答案遮蔽、匯出 CSV。結束後可手動刪除此場紀錄，不刪除題組。

## 學生端與資料保存

- 學號採字串保存，保留前導零；不限制為2–3位組員，輸入框沒有 maxlength。後端有60,000字元的極大請求保護上限，避免超過儲存限制。
- 兩句字卡混合；Who's／She's／He's 不拆，標點附字。支援點選與拖曳、Reset、聲音開關、系統減少動態偏好。
- 同組裝置重新整理會保留組別與當題草稿；未送達不扣次數，重送使用同一提交識別，不多扣一次。
- 題組、活動快照分開。題組後續修改不會改寫舊場次；學生只取得本組紀錄及目前題目素材。
- 保存場次、日期、班級、組號、所有學號、每次兩句答案、正誤、次數、時間；沒有自動到期刪除。
- 目前題組最多50題，圖片支援PNG/JPG/WebP、單張6 MB；七張來源圖均小於限制。
- 第5、7張原圖下緣含英文答案線索，依已確認規格保留原圖。七張封裝副本與來源 SHA-256 完全一致。
- 舊首頁 ZIP 備份包含舊圖片庫／課堂／入口；新活動紀錄使用自己的 CSV 匯出，不宣稱已包含在舊 ZIP。

## 架構與安全邊界

- 教師正式端沿用既有 Firebase custom token，仍驗證固定教師身分、claim、provider 與8小時時效。
- 新後端 `liveActivity` 處理教師 CRUD、學生加入、判分及控題。學生使用每組專屬隨機識別，不能使用教師 API 或讀其他组資料。
- `liveDecks`、`liveRooms` 與 `live-images` 不開放客戶端直讀寫，透過受驗證 API 存取；既有 Firestore/Storage 規則未放寬。
- 作答次數、判分、切題採 Firestore transaction。學生先送出的正誤欄位不受信任；伺服器以當題快照判分。
- 開放活動約每秒輪詢一次，結束後停止。真實網路／冷啟動延遲須於部署後另驗。
- 正式 JS 已检查不含 `local-teacher` 或 localhost API；本地教師替身僅位於 DEV 與本地伺服器，未驗證本次正式通行碼登入。
- 實作依據：[Firestore transactions](https://firebase.google.com/docs/firestore/manage-data/transactions)、[Local Emulator Suite](https://firebase.google.com/docs/emulator-suite/connect_firestore)。
