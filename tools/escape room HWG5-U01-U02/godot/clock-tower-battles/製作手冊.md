# Ken and the Frozen Clock Tower｜Godot 戰鬥製作手冊 v1

> 2026-10-18｜Godot 4.7.2（Compatibility、單執行緒 Web 模板）｜和 Forest of Words v07 分開，v07 沒有被修改。

## 玩法

- **流程**：每答 3 題進入一場戰鬥，共 11 場。網站先顯示介紹卡和這場的獎勵（4／3／2／1 星），按「▶ Start battle」才開始。
- **操作**：
  - 移動：畫面左下方向鍵（每根手指分開追蹤）或鍵盤 WASD／方向鍵。
  - 技能：右下「TICK TOCK!」或 Space／E。Tick-Tock Burst 範圍傷害，並清除敵方子彈，冷卻 14 秒。
  - Ken 會自動攻擊。
- **生命**：Ken 有 9 HP。HP 歸零會自動復活並計一次 recovery，戰鬥繼續。
- **時間**：第 1–9 場依序 20、21、22、23、24、25、26、28、30 秒；時間到就過關。第 10、11 場是 Boss，各 67 秒（教師要求由 60 秒延長 7 秒）。
- **略過**：可以略過戰鬥，仍拿到獎勵。紀錄會寫成 `skipped`，不會顯示成勝利。

| 場 | 場地 | 機關 |
|---|---|---|
| 1 | Clock Tower Plaza | 旋轉時針（開場 2 秒內無傷害） |
| 2 | Art Room | 顏料水窪：預警後讓 Ken 減速 |
| 3 | Music Hall | 兩座喇叭發出擴散聲波環 |
| 4 | Math Lab | 預警紅圈，積木落下 |
| 5 | Long Hall | 兩根反向旋轉的時針 |
| 6 | Language Room | 墨水雲減速＋紙片風帶推動 |
| 7 | Science Lab | 預警後出現的冒泡藥水池，持續傷害 |
| 8 | Gym and Map Room | 會反彈的球 |
| 9 | Rooftop | 較強的屋頂風帶 |
| 10 | Clock Core | Boss 第一階段：先破齒輪護盾，再把 HP 打到一半 |
| 11 | Clock Core | Boss 第二階段：打倒 Time Muncher |

## 獎勵怎麼影響戰鬥（品質 q＝1–4，沒拿到＝0）

| 道具 | 效果 |
|---|---|
| Paint Splash | 每 3.2 秒在最近的敵人處潑灑顏料，造成傷害並減速 |
| Music Note Shield | 減傷 9%×√q，上限 50% |
| Ruler Boomerang | 1–2 支尺繞著 Ken 旋轉攻擊 |
| Textbook Guard | 國語課本繞著 Ken 旋轉，擋下敵方子彈 |
| Word Bubble | 命中時連鎖打到附近另一個敵人 |
| Science Potion | 每 10 秒回復生命 |
| Speed Sneakers | 移動加速，也比較不會被風推動 |
| Globe Compass | 機關預警時間延長 12%×√q |
| 星期齒輪（最多 7） | 每個加 4% 傷害；Boss 護盾＝24−2×齒輪（最少 6） |
| Mirror Shard | 第 11 場 Boss 沒有護盾（沒拿到時護盾是 12） |

- **Boss 數值**：
  - 200 HP。第 10 場打到 100 就算第一階段成功。
  - 第 11 場從 100 HP 開始，不論第 10 場結果如何（故事會往下走），但結果頁照實記錄第 10 場是否成功。
- **計分分開**：學習分數只在網站計算，遊戲只回報戰果：defeated、recoveries、skillUses、bossHp、phaseCleared、bossDefeated。

## 檔案

| 檔案 | 用途 |
|---|---|
| `battle.gd`／`battle.tscn` | 戰鬥本體：模擬、Boss、繪圖、bridge |
| `battles.gd` | 11 場的名稱、提示、秒數、場地與敵人 |
| `assets/GAME-01–13.png` | 由 `assets/imagegen/game/` 主檔用 ffmpeg 縮成 1024 的複本（主檔沒有修改） |
| `tools/qa_battles.gd` | 無頭 QA：強／弱兩種配置跑完 11 場 |
| `tools/build-shell.py` | 每次匯出後產生 `site/public/game/index.html`：控制鍵、輸入權威與 postMessage 橋接 |
| `web/movement-input.mjs` | 每根手指分開追蹤的方向控制（來自 godot-games skill） |

## 重建

```powershell
$g = "$env:USERPROFILE\Downloads\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64_console.exe"
& $g --headless --path . --script res://tools/qa_battles.gd      # 必須看到 QA_BATTLES PASS
& $g --headless --path . --export-release "Web" "../../site/public/hwg5-u01-u02/game/engine.html"
python tools/build-shell.py                                       # 匯出後一定要重建 shell
```
