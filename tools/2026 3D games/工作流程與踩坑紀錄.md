## 三、各階段詳細流程

### 0. 需求釐清（RDQ）
- 大改動一律先產規格卡（`status: draft`），教師確認後改 `confirmed` 才做。
- 教師貼回建議清單＝全部採納；貼回假設清單＝同意這些假設。
- 已確認事項不重問；新對話先讀規格卡與交接筆記。

### 1. 影片分析
1. ffmpeg 抽音訊（16 kHz 單聲道）＋每 10 秒抽一張畫面，拼成縮圖看。
2. faster-whisper 語音辨識 → 逐字稿，人工校正同音字（「高德」＝Godot、「三式圖」＝三視圖）。
3. 報告只記方法、用自己的話改寫；影片原檔與截圖不放進專案。

### 2. 素材查證
- Tripo 以官方價格頁為準：Free 方案模型公開、非商用；Pro 可商用、私有。
- 13 個地點在 Google 地圖逐一看照片，**只用文字記特徵，不下載照片**；名稱以地圖為準（「二八水水公園」「水心之初大草原」）。
- 二水車站 2025-12 整修完成，外觀用最新照片。

### 3. 3D 建模（Tripo）
1. 參考圖：Tripo 免費額度用完後改 **ChatGPT API gpt-image-2**（medium、1024×1024，每張附 .json 與 SHA-256）。
2. 提示詞固定句：`stylized low-poly toy-like game asset, isolated on plain light grey background, three-quarter view from front-left, no people, no text`。
3. Generate HD Model：**Polycount 改 5000**、**Privacy 改 Private**；每個 55 點。
4. 匯出 GLB，用 GLB 內嵌貼圖名稱核對檔名，再複製到 `assets/models/`。

### 4. Godot 場景
- 路網用簡圖像素座標寫 `NODES`／`EDGES`，Dijkstra 找路；**Ken 永遠走在路中線**，地點的「門口」也在路上。
- 模型依外框置中、貼地、等比縮放到「最大邊長」（Ken 2.2、汽車 3.6、建築 8.5–22）。
- 鏡頭三種：走路越肩、打怪第一人稱、地圖俯視；鏡頭碰到建築會拉近。
- 自動測試：`-- --test`（流程＋截圖）、`--shots`（13 地點走路＋戰鬥截圖）、`--perf --mobile`（攻擊幀時間）。

### 5. 答題系統
- 規則沿用 HWG5 網站：品質 = max(1, 5 − 嘗試次數)；答錯出提示；答對聽 Tick 語音才可下一題（聽力題不用）。
- **遊戲不會打亂選項順序**，正解位置要在題庫裡先分散到 A／B／C。
- 缺音檔的聽力題用 `tools/generate_listening_tts.mjs`（gpt-4o-mini-tts／marin／0.8 倍速），whisper 轉文字核對。
- 圖片選項：ChatGPT API 生底圖；**數字（電話、房號、高度）用程式疊上去**，AI 畫數字常出錯。

### 6. 打怪
- 一般地點隨機 2 隻怪物（0.75 倍大小、站在門口前 7 m、左右間隔 2.3 m），魔王區各 1 隻（原大小）；愛心＝該地點題數。
- 答完全部題目 → 學生按 **Attack! 攻擊**（20 秒沒按自動發動、剩 2 擊以上可「全部發動」）。
- 8 種非暴力攻擊一律最華麗；4 星那一擊 Critical；魔王加震動、閃光、雙倍粒子、最後一擊慢動作煙火。

### 7. 聲音
- Suno 三首純音樂（免費方案：非商用、標示 Music: Suno）；Kenney CC0 音效 21 個。
- 答題時背景音樂降 20 dB，攻擊時恢復；右上角音量 4 段。
- **背景音樂不包進遊戲檔**：網頁版開始玩後從 `quest3d/music/` 背景下載（失敗重試 3 次），下載好才播。

### 8. 主角動畫
- Ken 原模型 195 萬面 → Tripo Retopology 1 萬面（35 點）→ Rig（20 點）→ walk、idle 預設動畫（不扣點），匯出勾 **Animation stay in Place**。
- Godot AnimationPlayer：走路播 walk、停下播 idle；Ken 變矮後動畫加速 1.3 倍、走速 7.6，腳才不會滑。

### 9. 網頁版匯出
1. Godot 匯出範本只解出 web 部分到 `%APPDATA%/Godot/export_templates/4.7.2.stable/`。
2. Web、不用多執行緒（Safari 不需特殊標頭）、只開 mobile 貼圖壓縮（Basis Universal）。
3. 中文字型：Noto Sans TC 用 `tools/build_cjk_font.py` 裁成遊戲用字；**加了新中文字串（例如錯誤訊息）要重跑**。
4. 匯出排除：測試截圖、題庫素材、舊 `ken.glb`、`assets/audio/music/*`。
5. 貼圖上限寫在各貼圖的 `.import`（不入 git）：建築／公園道具底色 768、小道具 512、Ken 底色 768、怪物 1024；粗糙度 256；**法線圖維持 512**。

### 10. 上架與教師後台
- 網頁外框（`shared/quest3d-app.mjs`）負責 Start、學號、存檔、上傳、結果頁；Godot 透過 `scripts/host.gd` 回報每題結果。
- Firestore：`questAttempts`（教師紀錄）；`questProgress`（換 iPad 接續，規則接受 `ershui-3d-quest` 與 `ershui-3d-quest-<代號>`）。
- 計分：Σ(100/題數 × 品質/4)，四捨五入。
- 先預覽頻道給教師 iPad 實測，教師說「部署正式站」才上線；部署前 `npm test`，部署後 curl 讀回。

### 11. 效能（iPad 攻擊卡頓）
- 開場「準備中」預熱所有特效、文字、音效（著色器先編譯）；材質共用；iPad 粒子減半放大。
- 物件池：特效物件開場建好，攻擊時只重複使用，不在攻擊途中新增／刪除節點。

### 12. 共用遊戲＋任務題庫
- 遊戲 `quest3d/` 只有一份；每個任務 `site/public/<任務>/`：`index.html`、`data.js`、`cover.webp`、`bank/`。
- 新任務：`tools/build_mission.py` → 放 `cover.webp` → 印出的一行貼進 `shared/missions.mjs`、卡片貼進首頁。格式：`tools/BANK-FORMAT.md`。
- 每個任務進度各自獨立（本機鍵 `quest3d:v1:<任務>:<學號>`；HWG5 R1 沿用舊鍵）。

### 13. iPad 讀題修正
- `bank/` 只放 `bank.json`＋一個 `bank-<內容雜湊>.pak`（所有插圖、語音、字型）；遊戲只下載兩個檔，失敗自動重試 3 次，依位元組顯示 %。
- pak 長期快取（immutable），題目一改檔名就變；遊戲檔 wasm／pck 快取 1 天。
- `build_mission.py` 會檢查音檔真實格式，副檔名 .mp3 但其實是 WAV 就用 ffmpeg 轉。

### 14. 新任務：六年級 HWG7 U01-U02
- `tools/convert_site_bank.py`：把情境任務網站的 `data.js`（28 題）＋English Lesson Hub 發音題庫（挑 10 題）＋`HWG 7 R1 Listening`（14 題）轉成 3D 題庫，配題在 PLANS／LISTEN／R1_ITEMS。
- 聽力音檔先用 faster-whisper 逐題核對；第 13、14 題用 TTS 補；第 4–8 題圖片選項用 `tools/make_hwg7_option_images.py`。
- 封面：二水街景＋on foot／Taiwan 插圖。

### 15. 比例、重疊與檔案大小（v5）
- 比例常數集中在 `world.gd` 開頭：`KEN_H`、`MONSTER_SCALE`、`FOE_DIST`、`FOE_GAP`、`CAR_LEN`。
- 汽車、機車、路燈、樹、矮樹叢擺放前都經 `_place_ok` 檢查：離 Ken 的路線至少身體半徑、不在建築外框內、不在戰鬥區；位置不合格就換下一個候選或不放。開場印 `OVERLAP CHECK: N problems`。
- 縮小遊戲檔先解析匯出的 `index.pck` 目錄找大檔，再逐項處理，每一步做前後截圖比對與 `--perf` 比對。

## 四、踩過的坑（症狀 → 原因 → 解法）

### 環境與工具
| 症狀 | 原因 | 解法 |
|---|---|---|
| faster-whisper 讀檔報 `metadata_errors` | PyAV 版本不相容 | 用 soundfile 讀成陣列再丟給模型 |
| PowerShell 5.1 執行含中文註解的 .ps1 出錯 | 編碼被當成 ANSI | .ps1 只寫英文 |
| bash 長 heredoc 含引號 `unexpected EOF` | 單引號衝突 | 改寫成 Python 腳本檔再執行 |
| 匯出範本下載到 849 MB 斷線 | 單次下載逾時 | `curl -C -` 斷點續傳＋重試 |
| `rm -rf` 被安全檢查擋下 | 刪除萬用字元路徑 | 不刪，直接覆蓋；要移除的東西改「搬到備份資料夾」 |
| 掃描 G 槽 `.godot` 資料夾卡十幾分鐘 | 幾千個快取小檔在 Google 雲端硬碟 | 不掃 `.godot`；要看遊戲檔內容就解析匯出的 `index.pck` |
| `git push` 報 `packed-refs.lock: File exists` | 舊鎖定檔殘留（Google 雲端同步） | push 其實成功；確認沒有其他 git 程序時再刪鎖定檔 |
| 部署報「Failed to get Firebase project」 | 沒指定帳號 | 一定加 `--project g6-english-online-learning --account u9431818@gmail.com` |

### Tripo
| 症狀 | 原因 | 解法 |
|---|---|---|
| 找不到匯出的 GLB | 下載位置被設成專案資料夾、或以 `.tmp` 存在 Downloads | 兩處都檢查；用 GLB 內嵌貼圖名稱辨認 |
| 連續匯出後半段沒下載 | Chrome 封鎖同站多檔下載 | 請教師允許多檔下載 |
| .tmp 被誤認成別的模型 | 用面數猜檔案不可靠 | 一律讀 GLB 的 images 名稱核對 |
| 模型 200 萬面、Sharing Only | Tripo 預設值 | 每次生成前改 Polycount 5000、Private |
| 中文招牌字錯 | AI 模型寫不好中文 | 中文一律在 Godot 用 Label3D／TextMesh 疊上 |
| 主角無骨架只能跳 | Tripo 模型是靜態雕像 | Retopology → Rig → walk／idle |

### Godot 與畫面
| 症狀 | 原因 | 解法 |
|---|---|---|
| 畫面太亮像玩具盒 | 環境光與色調預設 | 天空、遠山、Filmic 色調、調低環境光 |
| 第一人稱看到自己的腳 | 鏡頭目標用到 Ken 的位置 | 另存 `battle_center` 當鏡頭目標 |
| 怪物被建築／樹擋一半 | 只用中心點判斷遮擋 | 用物件外框與視線線段相交 |
| 怪物腳陷進馬路 | 路面高 0.2 m | 統一 `FOOT = 0.22` |
| **Ken 穿越汽車、機車插進建築、Ken 快一層樓高** | Ken 3.4 m 太大；汽車停得離路中線太近；機車沒檢查建築外框 | Ken 2.2 m、汽車 3.6 m；所有道具擺放前檢查路線／建築／戰鬥區；`OVERLAP CHECK`（10/23） |
| 兩隻怪物頭上的名字疊在一起 | 間隔 1.8 m 太近 | 間隔 2.3 m、怪物站近到 7 m |
| 攻擊時怪物名字被畫面上緣切掉 | 攻擊視角鏡頭仰角太高 | 攻擊視角下壓 4° |
| `previously freed instance` | 怪物被刪時協程還在跑 | 每個 await 後檢查 `is_instance_valid` |
| 自動測試互相干擾 | 測試流程與遊戲協程同時跑 | 測試等 `busy` 結束再進下一關 |

### 網頁版、題庫與 iPad
| 症狀 | 原因 | 解法 |
|---|---|---|
| 中文變方框 | 網頁不能用系統字型 | 打包 Noto Sans TC 子集；新字串要重做字型 |
| 遊戲檔 160 MB | 同時含電腦與 iPad 貼圖格式 | 只給 iPad、貼圖上限 1024 → 約 54 MB |
| **iPad 讀題庫很慢、漏檔、錯誤訊息有方框** | 一次抓 95 個小檔；內建字型缺新字 | 單一 `bank-<雜湊>.pak`、重試 3 次、重做內建字型（10/22） |
| pak 設 no-cache 後下載超慢 | Firebase CDN 不快取 no-cache 的檔 | 檔名加內容雜湊、長期 immutable 快取 |
| 學校網路第一次進遊戲要 10 分鐘以上 | 遊戲檔大、校網慢 | 遊戲檔縮小、快取 1 天；課前先開一次或用手機熱點 |
| **遊戲檔 index.pck 44.8 MB，伺服器壓縮沒用** | pck 內容本來就壓過；主要是貼圖、音樂、沒用到的舊 Ken | 排除舊 Ken、音樂背景下載、建築底色 768 → 25.1 MB（10/23） |
| 法線圖降到 256 後磁磚線變糊 | 法線圖決定表面凹凸細節 | 法線圖維持 512，只降粗糙度圖 |
| 教師的 .mp3 遊戲讀不出來 | 其實是 WAV，副檔名寫 .mp3 | `build_mission.py` 檢查檔頭、用 ffmpeg 轉 |
| 聽力題正解全在 A | docx 第一欄放正解，遊戲不打亂選項 | 轉題庫時把正解平均分到 A／B／C |
| 新任務換 iPad 不能接續 | Firestore 規則只認一個任務代號 | 規則接受 `ershui-3d-quest-<代號>` |
| 內建瀏覽器測試時畫面不動、讀題停住 | 分頁隱藏時頁面被暫停 | 顯示預覽窗格再測；看伺服器紀錄確認檔案有被要求 |
| 換了封面 iPad 還是舊的 | 圖片快取 1 天 | 重新整理或隔天再看 |
| iPad Safari 沒聲音 | Safari 要使用者先點畫面 | 進遊戲先點一下 |
| 攻擊明顯卡頓（70–94 ms） | 第一次畫特效要編譯著色器；每擊新建材質 | 預熱、材質共用、iPad 粒子減半 |
| 每隔 1–2 擊微卡 | 特效物件 1.6 秒後被刪除 | 物件池（**iPad 上仍待確認**；若靜音後不卡，下一步預先解碼音效） |

| 情況 | 學到的做法 |

## 五、標準步驟（速查）

### 只改題庫或新增任務（不用重新匯出遊戲）
1. 題目轉檔：HWG5 用 `python -I tools/build_quiz_data.py`；HWG7 用 `python -I -X utf8 tools/convert_site_bank.py --src hwg7-u01-u02 --out data/hwg7 --plan hwg7`。
2. `python -I -X utf8 tools/build_mission.py --mission <代號> --unit "<中文名>" --title "<英文名>" --questions <questions.json> --plan <quiz_plan.json>`。
3. 新任務才要：放 `cover.webp`、貼 `missions.mjs` 一行、貼首頁卡片。
4. 跳到「部署」。

### 改了遊戲本身
1. 改 Godot 程式或素材；有新中文字 → `python -I tools/build_cjk_font.py C:/Users/User/Godot/dl/NotoSansTC.ttf`。
2. 改了貼圖上限 → `Godot_console.exe --headless --path . --import`。
3. 測試：`-- --test --bank=<任務 bank>`（看 `OVERLAP CHECK: 0 problems`、`TEST DONE`）、`--shots`、`--perf --mobile`。
4. 匯出：`Godot_console.exe --headless --path . --export-release "Web" <site>/public/quest3d/index.html`。
5. **複製背景音樂**：`assets/audio/music/*.mp3` → `site/public/quest3d/music/`。

### 部署
1. `cd site && npm test`。
2. 預覽：`firebase hosting:channel:deploy ershui-preview --only hwg5-clock-tower --project g6-english-online-learning --account u9431818@gmail.com --expires 7d` → 教師 iPad 實測。
3. 教師同意 → `firebase deploy --only hosting:hwg5-clock-tower --project ... --account ...`（改規則時加 `,firestore:rules`）→ curl 讀回。
4. 收工：commit＋push（只放文字檔）。
