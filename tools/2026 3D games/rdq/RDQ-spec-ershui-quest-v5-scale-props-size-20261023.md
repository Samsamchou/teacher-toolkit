# RDQ 規格卡 v5｜主角比例、汽車／機車重疊、遊戲檔縮小

## 一段式需求規格
修正 iPad 試玩回報的三個問題：主角 Ken 穿越汽車、機車與建築重疊、Ken 身高快一層樓。
Ken 從 3.4 m 縮到 2.2 m，一般怪物同比例縮小（仍比 Ken 高一點）、魔王不變，
汽車縮到 3.6 m 並移到不擋路的路邊停車位，機車移到店門旁空地、不碰建築；
路燈與樹稍微縮小、鏡頭重新調整；加自動重疊檢查；遊戲裡加「Music: Suno」標示；
同時在「畫面與戰鬥品質不變」的前提下縮小遊戲資料檔 index.pck（目前 44.5 MB）。
完成後先截 13 個地點的圖給教師看，再部署預覽頻道給 iPad 實測，教師同意才上正式站。

## 遊戲檔縮小（教師新增需求：不影響畫面和戰鬥品質）
目前實際下載量（正式站實測）：引擎 index.wasm 7.1 MB（伺服器已壓縮）＋資料 index.pck 44.5 MB＋題庫約 10 MB。
要縮小的是 index.pck。依「不影響畫質」優先順序：
1. **移除沒用到的檔案**：例如未綁骨的舊主角 ken.glb（約 8.8 MB，遊戲用的是 ken_rigged）、其他未引用模型。畫質零影響。
2. **背景音樂改成進遊戲後才下載**：3 首 BGM 先不包進第一次下載，開始玩後在背景下載；畫質、戰鬥零影響，只是剛進遊戲的頭幾秒可能還沒音樂。
3. **小道具貼圖降解析度**：機車、路燈、汽車等小物件的貼圖 1024 → 512；建築、Ken、怪物維持原解析度。
4. 每一步都做前後截圖比對與 `--perf --mobile` 攻擊幀時間比對；看得出差別或變卡就退回該步。
目標：index.pck 降到 25 MB 以下（實際數字以量測為準，達不到會照實回報）。

## 驗收條件
- 電腦測試：Ken 走到 13 個地點都不穿車、不穿機車；自動重疊檢查 0 個問題。
- 13 個地點截圖：Ken 約三分之二層樓高、機車不插進建築、汽車在路邊。
- `--test` 通過；`--perf --mobile` 攻擊最長一格不比現在差。
- 兩個任務（HWG5 R1、HWG7）都能讀題進遊戲；npm test 全過。
- 先預覽頻道 → 教師 iPad 實測 → 教師說「部署正式站」才上線。
