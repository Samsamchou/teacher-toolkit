製作流程

依實際製作順序排列；每個大改動前都先跑一次 RDQ，規格卡確認後才動工。

  1. 需求釐清

    訪談 → 建議 → 規格卡（draft）→ 教師說「照這份開始」才做。

    rdq skill

  2. 影片分析

    抽音訊做語音辨識、每 10 秒抽一張畫面，整理方法（不保留影片素材）。

    ffmpeg · faster-whisper

  3. 素材查證

    Tripo 方案與授權；Google 地圖查 13 個地點外觀，只記文字特徵。

    內建瀏覽器 · Chrome

  4. 3D 建模

    參考圖 → Tripo 圖生 3D（5000 面、私人）→ 匯出 GLB。

    Tripo · ChatGPT API

  5. 街道場景

    依簡圖寫路網，13 地點、點了就走、越肩與第一人稱鏡頭。

    Godot 4.7.2

  6. 答題系統

    32 題拼字／拖放轉檔＋19 題聽力（音檔、插圖）。

    Python · OpenAI TTS

  7. 打怪

    答完全部題目 → 手動 Attack；8 種非暴力攻擊，魔王加碼。

    Tween · CPUParticles3D

  8. 聲音

    Suno 三首背景音樂、Kenney CC0 音效，答題時音樂自動降低。

    Suno · Kenney

  9. 主角動畫

    Ken 減面 → 綁骨 → walk／idle 預設動畫。

    Tripo Rig

  10. 網頁版匯出

    只給 iPad、中文字型子集、貼圖上限 1024。

    Godot export · fontTools

  11. 上架與後台

    學號外框、questAttempts／questProgress、預覽頻道 → 正式站。

    Firebase

  12. 效能修正

    iPad 攻擊卡頓：開場預熱、材質共用、物件池。

    --perf 測試

各階段細節

需求釐清（RDQ）
  • 大改動一律先產規格卡，教師確認後改成 confirmed。
  • 教師貼回建議清單＝全部採納；貼回假設清單＝同意那些假設。
  • 已確認事項不重問；新對話先讀規格卡和交接筆記。
3D 建模（Tripo）
  • 參考圖提示詞固定加上：stylized low-poly toy-like game asset、plain light grey background、three-quarter view、no people、no text。
  • Generate HD Model 前務必改：Polycount 5000（預設 200 萬）、Privacy 改 Private（預設 Sharing Only）。每個 55 點。
  • 匯出 GLB（2k 貼圖）不扣點；用 GLB 內嵌貼圖名稱核對檔名。
  • Tripo 免費生圖用完後，改用 ChatGPT API（gpt-image-2，medium）生參考圖再上傳。
答題系統
  • tools/build_quiz_data.py 從 HWG5 網站題庫轉出 data/questions.json 和 data/quiz_plan.json。
  • 品質＝max(1, 5−嘗試次數)；答錯一次出提示 1、兩次以上提示 2；拼字／拖放答對要聽完 Tick 語音才能下一題。
  • 聽力 11–17 題音檔：gpt-4o-mini-tts、marin、0.8 倍速，產生後用 whisper 轉文字核對。
打怪與特效
  • 一般地點隨機 2 隻（6 種原創怪物），魔王區各 1 隻；愛心數＝該地點題數。
  • 答完全部題目 → Combo → Attack! 攻擊（20 秒沒按自動發動；剩 2 擊以上可「全部發動」）。
  • 攻擊不得出現刀槍等武器：泡泡、光束、棒球、籃球、星星、水柱、火焰、強風。
  • 4 星那一擊 Critical；魔王加震動、閃光（≤0.15 秒）、雙倍粒子、最後一擊慢動作煙火。
聲音
  • Suno（免費方案）三首純音樂，轉 96 kbps 約 1.8 MB；非商用，要標示 Music: Suno。
  • Kenney CC0 音效 21 個共 157 KB，授權檔在 assets/audio/sfx/。
  • 答題時背景音樂降 20 dB（約 10%），攻擊時恢復；右上角音量四段，預設小聲。
主角動畫
  • 原模型 195 萬面 → Retopology 1 萬面（35 點）→ Rig Humanoid（20 點）。
  • Animation 預設 walk、idle 不扣點；匯出時選全部動畫並勾 Animation stay in Place。
上架與教師後台
  • 網頁外框負責 Start、學號、存檔、上傳；Godot 透過 scripts/host.gd 回報每題結果。
  • 紀錄寫進 questAttempts（沿用既有後台）；questProgress 讓同學號換 iPad 接續（不加密碼）。
  • 計分：每題 100÷題數 × 品質/4，總分四捨五入；題數由題庫自動計算。
  • 先部署預覽頻道給教師 iPad 實測，教師明說「部署正式站」才上正式站。

踩過的坑


改版步驟

在 2026 3D games/godot-ershui-quest 執行；網站在 escape room HWG5-U01-U02/site。

  1. 改 Godot 程式或素材。有新中文字時重建字型：
    python -I tools/build_cjk_font.py C:/Users/User/Godot/dl/NotoSansTC.ttf
  2. 有改題庫時重建題庫，再產生任務題庫資料夾（只改題庫不必重新匯出遊戲）：
    python -I tools/build_quiz_data.py
python -I -X utf8 tools/build_mission.py --mission ershui-3d-quest --unit "二水 3D 英語闖關 HWG5 R1" --title "Ershui 3D English Quest" --questions data/questions.json --plan data/quiz_plan.json
  3. 自動測試（--test 截圖、--shots 13 地點、--perf --mobile 攻擊幀時間），用 --bank= 指定題庫：
    Godot_v4.7.2-stable_win64_console.exe --path . --resolution 1280x720 -- --test --bank="../../escape room HWG5-U01-U02/site/public/ershui-3d-quest/bank"
  4. 改了遊戲本身才匯出，輸出到所有任務共用的 quest3d/：
    Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release "Web" "../../escape room HWG5-U01-U02/site/public/quest3d/index.html"
  5. 網站測試（在 site 資料夾）：
    npm test
  6. 部署預覽頻道給教師 iPad 實測：
    firebase hosting:channel:deploy ershui-preview --only hwg5-clock-tower --project g6-english-online-learning --account u9431818@gmail.com --expires 7d
  7. 教師同意後部署正式站，再讀回確認：
    firebase deploy --only hosting:hwg5-clock-tower --project g6-english-online-learning --account u9431818@gmail.com
  8. 收工：commit 並 push 到 GitHub。

換成六年級任務

可以。2026-10-21 已改成「共用遊戲＋任務題庫」：遊戲檔只有一份（quest3d/），題目、插圖、音檔、中文字型放在各任務的 bank/ 資料夾。新任務只要做一份題庫、跑一次 build_mission.py、放封面、首頁加卡片、後台清單加一行，不用重新匯出遊戲。格式見 godot-ershui-quest/tools/BANK-FORMAT.md。

可以直接沿用

  • 二水街道、13 個地點、模型、Ken 的動作
  • 怪物、魔王、8 種攻擊特效、音樂與音效
  • 三種題型的答題畫面（拼字、拖放、聽力）
  • 計分公式（題數會自動算，不必是 51 題）
  • 教師後台、學號外框、跨裝置接續（規則上限每份 60 題）

需要另外做

  • 六年級題庫轉成同樣格式（拼字、拖放、聽力）
  • 題目插圖、Tick 回饋語音、聽力音檔
  • 重新分配每個地點的題目（11 一般＋2 魔王）
  • 新的任務代號，例如 ershui-3d-quest-g6；build_mission.py 會建好資料夾與任務頁，並印出首頁卡片和後台清單那一行
  • 一張封面 cover.webp
python -I -X utf8 tools/build_mission.py --mission ershui-3d-quest-g6 --unit "二水 3D 英語闖關 HWG6" --title "Ershui 3D English Quest 6" --questions <questions.json> --plan <quiz_plan.json>
