## A. 程式生成動畫（不花錢、每格可重現、改起來快）

**共通技巧**（2026-11-04 從三支 Claude 程式 MV 歸納）：
- **歌詞→比喻道具**：逐句分鏡表多一欄，每句寫一個生活道具或場景比喻（收據、月曆、天平、告示牌…），讓每句的意思「看得見」。
- **數量說故事**：用一個→一排→一整面牆的角色數量表現孤單、從眾、團結。
- **全程式也能華麗**：三支參考 MV 都沒用 AI 生圖或生影片；要華麗不一定要花 KIE 點數。
- **技術備註**：參考 MV 用 Remotion（React 影片框架）＋Three.js；我們用 Canvas／Three.js＋Playwright，效果相同，不必換。
- 參考分析：`tools/2026 AI ANIMATED VIDEO/research/claude-mv-refs-20261104/分析報告.md`。

**更多共通技巧**（2026-11-04 從 Kurzgesagt 風教學片與 Blender P(doom) MV 歸納）：
- **參考圖鎖畫風法**：給 5–6 張目標風格截圖，要求逐項研究 ①配色 ②飽和度 ③發光效果 ④文字動畫，外加「細節多寡、2D 但有深度」。同一主題 v1 普通卡通 → v2 就有該畫風的味道。新畫風樣張一律用這招。
- **貫穿全片的儀表**：畫面角落放一個儀表（溫度計、心情表、進度條），每唱到關鍵字跳一格，最後一格有大事件。
- **科普旁白四步**（Kurzgesagt 式）：第二人稱把觀眾放進現場 →一個驚人比較 →「把一瞬間拉長」一步步拆解 →最後拉遠連到大問題；或同一件事分三種情況比快慢。
- **程式合成音效**：雨聲、撞擊、雷聲、點擊用 Python（numpy＋scipy）生成，分軌疊上；免費、可重現。「動畫 50%、聲音 50%」。
- **剪接卡在強拍**：除了逐字對時，再偵測拍點與強拍，換鏡頭落在強拍、動作重擊落在拍點。
- **一場景一檔、平行寫場景**：主 agent 管共用引擎與企劃，每個場景交給一個子 agent 寫自己的檔案，不准改共用程式（P(doom) 18 個場景就是這樣做）。
- 參考分析：`tools/2026 AI ANIMATED VIDEO/research/opus-kurzgesagt-blender-20261104/分析報告.md`；Blender 原始碼 GitHub `IdkwhatImD0ing/claude-music-videos`（MIT）。

### A9 What IF 情境猜句動畫（畫風 I，2026-11-13 新增；全片 v2 定案）
> **skill**：`whatif-situation-video`（範本 `output/whatif-ken-ershui/`，完整紀錄 `工作流程紀錄.md`）。下一支＝Free Time 版（HWG7 U03）。
> **第一支**：〈What if you were Ken in Ershui?〉（Ken 一週 11 個地點，Listen and Guess 句子＋時間句），專案 `tools/2026 AI ANIMATED VIDEO/output/whatif-ken-ershui/`，先讀 `HANDOFF.md`。3D 抵達鏡頭用小行星現成 Ken／車站模型在 Colab G4 Blender 渲染（第 1 鏡約 2 單位）。
> 參考：7 支「What IF」系列 YouTube 影片（Fly、Move Things、Read Minds、Zombie 三部曲、10x Stronger）。分析報告 `tools/2026 AI ANIMATED VIDEO/research/whatif-refs-20261113/分析報告.md`。只學做法，角色用我們自己的（Ken、圳寶、水鈴）。
- **輸入**：一句情境句（Ken 情境題：`Where are you going? — I'm going to the ___.`）＋該地點的線索（環境音、兩個圖示、默劇動作）。
- **片子結構（建議，RDQ 確認）**：「What if you were Ken in Ershui…?」第二人稱開場 → 聽問句 → 三種線索一個一個出現（聲音→圖示→動作）→ 3 秒倒數猜 → 答案揭曉（地點大字＋3D 鏡頭走到門口）→ 一次一個字大字幕跟讀。每句 20–40 秒，一支 1–3 分鐘。
- **2D 部分**（畫風 G 引擎／HyperFrames 或 Canvas＋Playwright）：扁平夜色、光束、雲層、多層視差、大數字標籤；角色用 Ken 的 2D 立牌（Codex 生成、A 字站姿、只換眼嘴表情貼片）。
- **3D 部分**（1–2 個鏡頭）：用二水小行星現成的 Ken 綁骨模型＋地點建築（`3D planet/godot-ershui-planet/`），在 Three.js（畫風 E 引擎）或 Blender（Colab G4）渲染，例如「鏡頭從天空俯衝到二水車站」；3D 鏡頭套同一組紫藍配色＋輪廓光，和 2D 接得起來。
- **聲音**：沿用小行星的 edge-tts 句子音檔（Jenny 問、Guy 答）或另配；程式音效＋Kenney CC0；配樂很小聲。
- **字幕**：Comic Relief Bold 整句**英文**卡拉 OK（念過變橘、正在念的字加底線、上方說話者標籤）；**不放中文字幕**（老師 11/13 決定，中文句意只放在 Google 文件故事稿）。
- **品質標準**：鏡頭永遠在動、一格一個重點、聲音 50%、約 3 秒一刀；不要驚嚇或暴力畫面。
- **流程**：RDQ → 畫風樣張 1 張（Ken＋二水夜景）→ 1 句試片（2D＋3D 各一鏡）→ 老師核准 → 其餘句子平行做 → 縮圖總表 → 字幕版＋聽力版。

### A8 看動畫猜句子圖示影片（畫風 G，2026-11-10 定案）
- **輸入**：一組片語＋句型（例：`I ________ in my free time.`）
- **流程**：RDQ → 每段情節照現實順序 → 2 支試片（老師核准）→ 其餘段落交給子代理平行寫（一段一檔，共用說明 `SEGMENT_BRIEF.md`）→ 每段 16 格縮圖總表檢查動作邏輯 → `build.py` 一鍵輸出單段 MP4＋合輯
- **格式**：剪影動作約 10 秒 → 倒數 3 秒（嗶）→ 答案填入句子（叮，動詞金色、其餘紅色）；字幕列在 y 835 以上，不要太下面；Comic Relief
- **正式案例**：Free Time 11 段（`tools/2026 AI ANIMATED VIDEO/output/free-time-guess/`，合輯 3:15）

### A2 真人 MV → 2D 動畫（2026-10-30 新增）
- **skill**：`mv-to-2d-animation`（沿用 A1 的引擎與檢查表）
- **輸入**：真人演出的音樂錄影帶影片檔（.mp4）

- **特色**：保留原 MV 劇情主線、副歌句子動作化；雙語字幕（英文或原文＋中文句意）；非英文段用原文字幕；刻板印象句不畫膚色；只在課堂播放

### A3 旁白式 2D 教學影片
- **skill**：`narrated-2d-videos`
- **輸入**：一個主題（集集線、八堡圳、二水…）
- **流程**：上網查證 → Google 文件腳本 → 逐句（句意）分鏡表 → edge-tts 台灣口音試配音 → 角色與畫風樣張 → 逐張生圖給老師看（gpt-image-2，Canva 備用）→ 試片 → 全片 → 逐句抽格 → 驗收
- **特色**：繁體中文台灣口音旁白；AI 插圖＋程式動畫字卡；真實地點要先查最新照片
- **正式案例**：集集線五站 2D v1（3 分鐘）、延長版 v2.1（5:08）（`tools/2026 AI ANIMATED VIDEO/output/jiji-line/`）

### A5 3D 模型雙老師教學動畫

### A6 MV／歌曲 → 3D 動畫（畫風 E，2026-11-05 新增）

5. **共用引擎**（Three.js 0.180，程式自己寫，不換 Remotion）：
   - `world.js`：OutlineEffect 描邊、卡通材質；**灰轉彩著色器**（uSat 灰↔彩、uHue 只換衣服顏色、uJacket 外套變色、uGlow 提亮；膚色判斷要在 sRGB 做）。

13. **聽力版**（nosub=1 全片重渲，場景裡的歌詞招牌保留、只拿掉紙條字幕）→ 驗收。

**花費**：全部本機渲染；只花 Tripo（7 個角色 505 點）＋ KIE 試拍 19 點。全片 4:25 本機渲染約 1.5 小時（3 個場景平行）。

**畫風 E 踩坑**：
- GLTF 會拿掉 Mixamo 骨頭名稱的冒號（`mixamorigHead`）→ 用 `/^mixamorig:?/` 對應。
- 綁骨角色移位後要 `holder.updateMatrixWorld(true)`，射線和骨頭座標才對。
- 每格**先放鏡頭**再擺看板、對話框（才會正確轉向鏡頭）。
- 正上方聚光燈會讓下巴發黑 → 斜前方聚光＋跟著鏡頭的補光。
- 換色碰到膚色 → 膚色判斷改在 sRGB。
- 群眾 InstancedMesh 要 `frustumCulled = false`；`scene.background` 用貼圖＋OutlineEffect 會隔格閃 → 純色背景＋天空平面。
- 卡通大頭角色坐在書桌前，胸口比桌面低 → 椅子加坐墊，手放胸口才看得到。

- 寫 JS 不用 Bash heredoc（`\n` 會變真換行）；用 Python 取代字串時，行中註解一律用 `/* */`，`//` 會把同一行後面的程式一起註解掉。
- `render3d.py --still` 吃「場景本地秒」，不是全曲秒。

- 本機 EEVEE 比 Cycles 亮很多，只拿來看構圖；顏色和光線以 Cycles 為準。

## 程式動畫 vs AI 短片，怎麼選？

| | 程式生成動畫（A） | AI 生成短片（B） |
|---|---|---|
| 成本 | 不花錢（本機渲染） | 花 Colab 單位或 KIE 點數 |
| 角色一致 | 全片完全一致 | 要用首幀／角色表鎖，偶爾走樣要重抽 |
| 對到歌詞／句意 | 可以精準卡在唱到的那個字 | 較難精準控制時間點 |
| 畫面質感 | 可選 A–F 畫風；做 3D 場景、運鏡、燈光也能很華麗 | 接近電影或動畫片質感 |
| 修改 | 改程式重渲染該場景 | 要重新生成（再花錢） |
| 適合 | 歌曲、每句要對到動作的教學影片 | 故事情境、對話短片、大動作鏡頭 |

**混用**：A 為主、B 補高潮鏡頭（例：A2 Stand Out Fit In v2 用 KIE 補 5 個舞獅鏡頭）；或 B 為主、程式疊字幕與圖卡（例：B3 SF3 R1 用程式疊月曆天氣）。

## 共用：Phonics 教學影片規則（2026-11-11，Poe the Goat 定下）
所有 phonics 教學影片（B4 專屬 skill `phonics-story-video`；A5 雙老師、程式動畫也照這些規則）：
- **三色標目標拼法**：例 o_e 紅、oa 藍、ow 綠；AI 畫面裡不出現字，字全部程式疊。
- **每句 3 次**：Listen（0.8 倍、卡拉 OK）→ Listen again（0.65 倍，目標字母**念到那個字才變色**，用逐字時間）→ Your turn（模糊背景＋整句三色字＋5 秒倒數，長句 7 秒）。
- **分類**：目標字一個一個念出來、分進各拼法欄。
- **測驗誘答選項（老師 11/11 指定）**：誘答字要「長得像、但母音拼法不同」——改成短母音或另一種拼法，例 boat → **bot**、snow → **snoke**、robe → **rob**。**不可用同音異拼**（bowt、snoa、roab）：念起來一樣，學生聽了無從判斷。
- **片尾完整故事不停頓播一次**（測驗之後、The End 之前）。
- 範本程式：`tools/2026 AI VIDEOS SENSE BAR/films/poe-the-goat/scripts/build_film.py`（也在 skill 的 `assets/template/`）。
