## A. 程式生成動畫（不花錢、每格可重現、改起來快）

共通點：Canvas 2D（或 3D 模型）程式畫面＋Playwright 逐格截圖＋ffmpeg 合成；每一句歌詞或句意都要有對應畫面；每一步停下來給老師確認；2D 可選畫風 **A 平塗繪本／B 電影光影／C 黑底塗鴉**（10/24 核准）。

### A1 歌曲 2D 動畫（MP3＋歌詞）
- **skill**：`2d-animations`（也負責用 Suno 模板寫新的兒童英語歌）
- **輸入**：教學歌 MP3＋歌詞 Word 檔
- **流程**：討論流程 → 本機語音辨識對時 → 逐句分鏡表 → 兩場景試片 → 全曲（字幕版＋聽力版）→ 逐句抽格驗收
- **特色**：角色對嘴原曲；六位學生角色；副歌群舞共用編舞
- **正式案例**：How Do You Go 2D v1、Every Day Is Fun 2D v1（`tools/2026 AI ANIMATED VIDEO/output/how-do-you-go/2d-v1/`、`every-day-is-fun/2d-v1/`，新歌從 every-day-is-fun 複製引擎）

### A2 真人 MV → 2D 動畫（2026-10-30 新增）
- **skill**：`mv-to-2d-animation`（沿用 A1 的引擎與檢查表）
- **輸入**：真人演出的音樂錄影帶影片檔（.mp4）
- **流程**：RDQ → 讀影片（縮圖總表）→ 歌詞對時（非英文段另跑、用原 MV 字幕交叉比對）→ **逐句分析表「歌詞 × 原 MV 動作 × 改編動作」**（MD＋Google 文件）→ 兩場景試片 → 全片 → 選用 KIE AI 以 2D 畫面當首幀補 3–5 個高潮鏡頭
- **特色**：保留原 MV 劇情主線、副歌句子動作化；雙語字幕（英文或原文＋中文句意）；非英文段用原文字幕；刻板印象句不畫膚色；只在課堂播放
- **案例**：ONE OK ROCK〈Stand Out Fit In〉v1／v2（`tools/2026 AI ANIMATED VIDEO/output/stand-out-fit-in/2d-v2/`）
- **完整流程與踩坑**：`tools/2026 AI VIDEOS SENSE BAR/films/stand-out-fit-in/工作流程與踩坑紀錄.md`

### A3 旁白式 2D 教學影片
- **skill**：`narrated-2d-videos`
- **輸入**：一個主題（集集線、八堡圳、二水…）
- **流程**：上網查證 → Google 文件腳本 → 逐句（句意）分鏡表 → edge-tts 台灣口音試配音 → 角色與畫風樣張 → 逐張生圖給老師看（gpt-image-2，Canva 備用）→ 試片 → 全片 → 逐句抽格 → 驗收
- **特色**：繁體中文台灣口音旁白；AI 插圖＋程式動畫字卡；真實地點要先查最新照片
- **正式案例**：集集線五站 2D v1（3 分鐘）、延長版 v2.1（5:08）（`tools/2026 AI ANIMATED VIDEO/output/jiji-line/`）

### A4 節奏單字朗讀影片
- **skill**：`rhythm-vocabulary-video`
- **輸入**：單字＋圖片，或學生掃描作品
- **流程**：本機裁圖 → 老師與兒童感雙聲線 → 0.85 倍自然朗讀對拍 → 黑板圖卡動畫（8／9／16／32 張配置）
- **特色**：沒有劇情角色，重點是跟節奏朗讀

### A5 3D 模型雙老師教學動畫
- **skill**：沒有專屬 skill（**仍在進行中，老師 2026-10-30 決定先不整理成 skill**）；規則在專案資料夾與記憶（科幻雙老師）
- **輸入**：發音或句型教學內容
- **流程**：RDQ → 腳本 → TTS 配音（英文 Ava／中文小晨 HsiaoChen，0.8 倍）→ 3D 模型（GLB）姿勢與嘴型 → 本機 12 執行緒分段渲染
- **特色**：發音一律用老師錄音或 Wikimedia，不用 TTS；全部本機渲染（不用 RunPod）
- **案例**：影片 1〈星期〉v1.2 定案（8:45）；影片 2 待驗收（`tools/2026 AI ANIMATED VIDEO/output/sci-fi-teachers/`）

## B. AI 生成短片（AI 生成畫面，要先報成本）

共通點：生成前一定先報 Colab 運算單位或 KIE 點數；角色要用首幀或角色表鎖住長相；老師在每個關卡看過才往下；配音、字幕、配樂在後製由程式疊上。

### B1 山獅霸 Colab 短片（從故事點子開始）
- **依據**：兩個 GitHub repo（shanshiba-workflow-colab、shanshiba-workflow-32gvram-64gram）＋記憶
- **流程**：腳本 → Qwen-Image 角色與首幀 → Breeze 配音參考 → MiniMax H3 影片 → 後製 → 自我檢查；三個關卡（首幀總表、影片片段、成片）
- **注意**：開 G4 前查 `colab usage` 並說明單位；H3 授權地區問題由老師決定；僅限非商業
- **範本片**：〈被狗吃掉的作業〉2026-10-23 驗收

### B2 HWG 句型短片（只用 Colab H3）
- **skill**：`hwg-sentence-film-h3`（2026-10-30 建立）
- **依據**：記憶＋`tools/shortsaboutsentences/` 的交接
- **流程**：已核准的首幀／尾幀＋固定配音 → Colab H3 批次 → 自動檢查（亮度、音訊、嘴型）→ 老師用手機看 → 組裝（ASS 字幕、響度 −16 LUFS）
- **案例**：HWG5 U03 完整版 2026-10-23 核准

### B3 混合 AI 短片（KIE Seedance 動作鏡＋Colab H3 對話鏡）
- **skill**：`hybrid-ai-film`（2026-10-30 建立）
- **依據**：`tools/2026 AI VIDEOS SENSE BAR/HWG 7 U04 FILM/HANDOFF.md`、`SF3 R1 Daily talk/HANDOFF.md`
- **流程**：Codex 首幀 → 配音（VoxCPM2）→ 對話鏡用 H3、大動作鏡用 KIE Seedance 2.0 Mini → 配樂 → `assemble.py`
- **老師偏好**：配音 0.7–0.8 倍；Comic Relief 卡拉 OK 字幕、字要大（後排看得到）；配樂很小聲
- **案例**：HWG7 U04〈A Day with the Elves〉（10/24）、SF3 R1〈A Sunday with Grandma〉（10/26）

## 程式動畫 vs AI 短片，怎麼選？

| | 程式生成動畫（A） | AI 生成短片（B） |
|---|---|---|
| 成本 | 不花錢（本機渲染） | 花 Colab 單位或 KIE 點數 |
| 角色一致 | 全片完全一致 | 要用首幀／角色表鎖，偶爾走樣要重抽 |
| 對到歌詞／句意 | 可以精準卡在唱到的那個字 | 較難精準控制時間點 |
| 畫面質感 | 平塗卡通（可選 A／B／C 畫風） | 接近電影或動畫片質感 |
| 修改 | 改程式重渲染該場景 | 要重新生成（再花錢） |
| 適合 | 歌曲、每句要對到動作的教學影片 | 故事情境、對話短片、大動作鏡頭 |

**混用**：A 為主、B 補高潮鏡頭（例：A2 Stand Out Fit In v2 用 KIE 補 5 個舞獅鏡頭）；或 B 為主、程式疊字幕與圖卡（例：B3 SF3 R1 用程式疊月曆天氣）。
