## A. 程式生成動畫（不花錢、每格可重現、改起來快）

共通點：Canvas 2D（或 3D 模型）程式畫面＋Playwright 逐格截圖＋ffmpeg 合成；每一句歌詞或句意都要有對應畫面；每一步停下來給老師確認。

**畫風選單**（新畫風都先用我們自己的角色畫一張樣張，老師核准才列為正式選項）：

| 畫風 | 長相 | 適合 | 狀態 |
|---|---|---|---|
| A 平塗繪本 | 平塗色塊、可愛角色 | 一般教學歌 | ✅ 正式 |
| B 電影光影 | 黃昏色調、窗光、單側暖色輪廓光、背景模糊 | 有情緒的歌、劇情 MV | ✅ 10/24 核准 |
| C 黑底塗鴉寓言 | 黑底、手寫字卡、一個紅色重點、心情變好顏色回來 | 寓言、心情轉折 | ✅ 10/24 核准 |
| D 動態文字糖果風 | 粉彩放射線／棋盤格背景、超大歌詞逐字跳出、生活道具（收據、月曆、聊天框）、漫畫貼紙 | 要學生看字跟唱的歌、句型歌 | ⏳ 11/04 樣張待核准 |
| E 3D 世界文字＋灰轉彩 | 3D 場景（Three.js），歌詞是招牌、黑板、地板字；攝影機在場景裡飛；網點陰影；世界從灰色變彩色 | 有成長／改變劇情的歌 | ⏳ 11/04 樣張待核准（Stand Out Fit In v3 採用） |
| F 紙箱小劇場 | 鞋盒舞台＋縫線外框、方塊紙箱人、燈光分段、底部紙條字幕（關鍵字紅色） | 講群體、合群、團隊的故事；寓言 | ⏳ 11/04 樣張待核准 |
| G 扁平科普風（Kurzgesagt 式） | 扁平向量插畫、深紫藍夜色、發光（閃電、星光）、**只有一個紅色重點**、粗體科普標籤＋小副標、地球剖面與數字比較 | 自然、社會、在地課程的科普短片（「有多大？多快？多少？」） | ✅ 11/04 核准（10 秒試片〈I go to school by bus.〉，HyperFrames；`tools/2026 AI ANIMATED VIDEO/output/style-pilots-20261104/g-flat-science/`） |
| H 桌上微縮定格（Blender） | 夜晚書桌是整個世界；玩具尺寸角色、微距淺景深、檯燈暖光；角色每 2 格換姿勢（定格感）；物理模擬（雪崩、骨牌、煙） | 有「小東西長成大世界」劇情的歌或故事 | ✅ 11/05 核准（10 秒試片〈I go to school by bus.〉：Nova 換 Tripo 姿勢模型＝定格感、Tripo 道具、Colab G4 Cycles；`tools/2026 AI ANIMATED VIDEO/output/style-pilots-20261104/h-tabletop/`） |

**共通技巧**（2026-11-04 從三支 Claude 程式 MV 歸納）：
- **歌詞→比喻道具**：逐句分鏡表多一欄，每句寫一個生活道具或場景比喻（收據、月曆、天平、告示牌…），讓每句的意思「看得見」。
- **數量說故事**：用一個→一排→一整面牆的角色數量表現孤單、從眾、團結。
- **全程式也能華麗**：三支參考 MV 都沒用 AI 生圖或生影片；要華麗不一定要花 KIE 點數。
- **技術備註**：參考 MV 用 Remotion（React 影片框架）＋Three.js；我們用 Canvas／Three.js＋Playwright，效果相同，不必換。
- 參考分析：`tools/2026 AI ANIMATED VIDEO/research/claude-mv-refs-20261104/分析報告.md`。

**更多共通技巧**（2026-11-04 從 Kurzgesagt 風教學片與 Blender P(doom) MV 歸納）：
- **參考圖鎖畫風法**：給 5–6 張目標風格截圖，要求逐項研究 ①配色 ②飽和度 ③發光效果 ④文字動畫，外加「細節多寡、2D 但有深度」。同一主題 v1 普通卡通 → v2 就有該畫風的味道。新畫風樣張一律用這招。
- **貫穿全片的儀表**：畫面角落放一個儀表（溫度計、心情表、進度條），每唱到關鍵字跳一格，最後一格有大事件。
- **科普旁白四步**（Kurzgesagt 式）：第二人稱把觀眾放進現場 →一個驚人比較 →「把一瞬間拉長」一步步拆解 →最後拉遠連到大問題；或同一件事分三種情況比快慢。
- **程式合成音效**：雨聲、撞擊、雷聲、點擊用 Python（numpy＋scipy）生成，分軌疊上；免費、可重現。「動畫 50%、聲音 50%」。
- **剪接卡在強拍**：除了逐字對時，再偵測拍點與強拍，換鏡頭落在強拍、動作重擊落在拍點。
- **一場景一檔、平行寫場景**：主 agent 管共用引擎與企劃，每個場景交給一個子 agent 寫自己的檔案，不准改共用程式（P(doom) 18 個場景就是這樣做）。
- 參考分析：`tools/2026 AI ANIMATED VIDEO/research/opus-kurzgesagt-blender-20261104/分析報告.md`；Blender 原始碼 GitHub `IdkwhatImD0ing/claude-music-videos`（MIT）。

### A1 歌曲 2D 動畫（MP3＋歌詞）
- **skill**：`2d-animations`（也負責用 Suno 模板寫新的兒童英語歌）
- **輸入**：教學歌 MP3＋歌詞 Word 檔
- **流程**：討論流程 → 本機語音辨識對時 → 逐句分鏡表 → 兩場景試片 → 全曲（字幕版＋聽力版）→ 逐句抽格驗收
- **特色**：角色對嘴原曲；六位學生角色；副歌群舞共用編舞
- **正式案例**：How Do You Go 2D v1、Every Day Is Fun 2D v1（`tools/2026 AI ANIMATED VIDEO/output/how-do-you-go/2d-v1/`、`every-day-is-fun/2d-v1/`，新歌從 every-day-is-fun 複製引擎）

### A2 真人 MV → 2D 動畫（2026-10-30 新增）
- **skill**：`mv-to-2d-animation`（沿用 A1 的引擎與檢查表）
- **輸入**：真人演出的音樂錄影帶影片檔（.mp4）
- **流程**：RDQ → 讀影片（縮圖總表）→ 歌詞對時（非英文段另跑、用原 MV 字幕交叉比對）→ **逐句分析表「歌詞 × 原 MV 動作 × 改編動作 × 比喻道具」**（MD＋Google 文件）→ 兩場景試片 → 全片 → 選用 KIE AI 以 2D 畫面當首幀補 3–5 個高潮鏡頭
- **特色**：保留原 MV 劇情主線、副歌句子動作化；雙語字幕（英文或原文＋中文句意）；非英文段用原文字幕；刻板印象句不畫膚色；只在課堂播放
- **案例**：ONE OK ROCK〈Stand Out Fit In〉v1／v2（`tools/2026 AI ANIMATED VIDEO/output/stand-out-fit-in/2d-v2/`）；v3 改用畫風 E 真 3D 重做中（2026-11-04 起，`3d-v3/`）
- **完整流程與踩坑**：`tools/2026 AI VIDEOS SENSE BAR/films/stand-out-fit-in/工作流程與踩坑紀錄.md`

### A3 旁白式 2D 教學影片
- **skill**：`narrated-2d-videos`
- **輸入**：一個主題（集集線、八堡圳、二水…）
- **流程**：上網查證 → Google 文件腳本 → 逐句（句意）分鏡表 → edge-tts 台灣口音試配音 → 角色與畫風樣張 → 逐張生圖給老師看（gpt-image-2，Canva 備用）→ 試片 → 全片 → 逐句抽格 → 驗收
- **特色**：繁體中文台灣口音旁白；AI 插圖＋程式動畫字卡；真實地點要先查最新照片
- **正式案例**：集集線五站 2D v1（3 分鐘）、延長版 v2.1（5:08）（`tools/2026 AI ANIMATED VIDEO/output/jiji-line/`）

### A4 節奏單字朗讀影片
- **skill**：`rhythm-vocabulary-video`
- **輸入**：單字＋圖片，或學生掃描作品
- **流程**：本機裁圖 → 老師與兒童感雙聲線 → 0.85 倍自然朗讀對拍 → 黑板圖卡動畫（8／9／16／32 張配置）
- **特色**：沒有劇情角色，重點是跟節奏朗讀

### A5 3D 模型雙老師教學動畫
- **skill**：`3d-teacher-lesson-video`（2026-11-01 建立；含逐步流程、約 70 條踩坑與修法、引擎程式範本）
- **輸入**：發音或句型教學內容
- **流程**：RDQ → 角色設定與報價 → 定裝圖 → Tripo 姿勢模型（GLB）→ 嘴形／眨眼貼片 → 真人發音音檔 → Google 文件腳本 → edge-tts 配音（0.8 倍）＋whisper 核對 → 插圖 → 試片 → 本機 8 段平行渲染 → 720p 預覽 → 驗收；選用學生對話華麗版（Codex 素材＋剪紙動畫＋斜臉嘴型換圖）
- **特色**：發音一律用老師錄音或 Wikimedia，不用 TTS；全部本機渲染（不用 RunPod）
- **案例**：影片 1〈星期〉v1.3、影片 2〈What day is today?〉v2.3、影片 3〈Is it ___ today?〉v1.2，2026-11-03 全部定案（新片從 `video3-isit/` 複製）（`tools/2026 AI ANIMATED VIDEO/output/sci-fi-teachers/`）

## B. AI 生成短片（AI 生成畫面，要先報成本）

共通點：生成前一定先報 Colab 運算單位或 KIE 點數；角色要用首幀或角色表鎖住長相；老師在每個關卡看過才往下；配音、字幕、配樂在後製由程式疊上。

### B1 山獅霸 Colab 短片（從故事點子開始）
- **依據**：兩個 GitHub repo（shanshiba-workflow-colab、shanshiba-workflow-32gvram-64gram）＋記憶
- **流程**：腳本 → Qwen-Image 角色與首幀 → Breeze 配音參考 → MiniMax H3 影片 → 後製 → 自我檢查；三個關卡（首幀總表、影片片段、成片）
- **注意**：開 G4 前查 `colab usage` 並說明單位；H3 授權地區問題由老師決定；僅限非商業
- **範本片**：〈被狗吃掉的作業〉2026-10-23 驗收

### B2 HWG 句型短片（只用 Colab H3）
- **skill**：`hwg-sentence-film-h3`（2026-10-30 建立）
- **依據**：記憶＋`tools/shortsaboutsentences/` 的交接
- **流程**：已核准的首幀／尾幀＋固定配音 → Colab H3 批次 → 自動檢查（亮度、音訊、嘴型）→ 老師用手機看 → 組裝（ASS 字幕、響度 −16 LUFS）
- **案例**：HWG5 U03 完整版 2026-10-23 核准

### B3 混合 AI 短片（KIE Seedance 動作鏡＋Colab H3 對話鏡）
- **skill**：`hybrid-ai-film`（2026-10-30 建立）
- **依據**：`tools/2026 AI VIDEOS SENSE BAR/HWG 7 U04 FILM/HANDOFF.md`、`SF3 R1 Daily talk/HANDOFF.md`
- **流程**：Codex 首幀 → 配音（VoxCPM2）→ 對話鏡用 H3、大動作鏡用 KIE Seedance 2.0 Mini → 配樂 → `assemble.py`
- **老師偏好**：配音 0.7–0.8 倍；Comic Relief 卡拉 OK 字幕、字要大（後排看得到）；配樂很小聲
- **案例**：HWG7 U04〈A Day with the Elves〉（10/24）、SF3 R1〈A Sunday with Grandma〉（10/26）

## C. 共通工具（A、B 兩類都可用）

### WIP 審片工具（選用，2026-11-04 新增）
- **來源**：GitHub `Imaginative-Prompting/wip`（MIT 授權），本機執行（Node.js 22 以上），不需帳號、不上傳。
- **用途**：所有版本（v1、v2、v3、試片）放在同一個清單＋一個播放器；可逐格前後看。
- **老師回饋方式**：暫停後直接在畫面上**畫圈、畫箭頭**，按幀號就把「片名、版本、第幾格」複製給我，取代「大概 2 分 10 秒那裡」。
- **注意**：標註與資料都只在本機；不使用它的匯出網站功能，避免課堂影片外流。

### 其他程式渲染工具（選用，2026-11-04 記錄）
- **HyperFrames**（HeyGen 開源，Apache-2.0，`npx hyperframes`）：寫 HTML＋GSAP 動畫直接渲染 MP4，附預覽編輯器 Studio。跟我們 Canvas＋Playwright 同一類，畫風 G 可以用它或沿用現有引擎。
- **Blender 5.2**（免費）：Python 腳本建模、骨架、物理模擬、渲染；畫風 H 才需要。已裝在 `C:\Users\User\blender-5.2`（5.2.2 免安裝版）。實測 1080p：本機（Intel 內建顯示）EEVEE 每格 8–9 秒，用來試做與縮圖總表；**正式渲染用 Colab G4 Cycles＋OptiX，每格約 2.7 秒**（10 秒片約 11 分鐘；3 分鐘片約 3.2 小時、約 33–35 單位）。Colab 上 EEVEE 起不來（EGL），不要用。流程：本機 EEVEE 縮圖總表 → 老師核准 → G4 先渲 3 張 Cycles 確認光線 → 全片 → 雲端 zip 下載 → `colab stop`。

## 程式動畫 vs AI 短片，怎麼選？

| | 程式生成動畫（A） | AI 生成短片（B） |
|---|---|---|
| 成本 | 不花錢（本機渲染） | 花 Colab 單位或 KIE 點數 |
| 角色一致 | 全片完全一致 | 要用首幀／角色表鎖，偶爾走樣要重抽 |
| 對到歌詞／句意 | 可以精準卡在唱到的那個字 | 較難精準控制時間點 |
| 畫面質感 | 可選 A–F 畫風；做 3D 場景、運鏡、燈光也能很華麗 | 接近電影或動畫片質感 |
| 修改 | 改程式重渲染該場景 | 要重新生成（再花錢） |
| 適合 | 歌曲、每句要對到動作的教學影片 | 故事情境、對話短片、大動作鏡頭 |

**混用**：A 為主、B 補高潮鏡頭（例：A2 Stand Out Fit In v2 用 KIE 補 5 個舞獅鏡頭）；或 B 為主、程式疊字幕與圖卡（例：B3 SF3 R1 用程式疊月曆天氣）。
