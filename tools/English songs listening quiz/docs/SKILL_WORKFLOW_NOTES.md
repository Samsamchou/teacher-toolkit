# 未來技能的流程素材 / Notes for a future skill

狀態：流程筆記，尚非已安裝或已驗收的 Skill。

1. 指定工作根目錄、檢查父層規則与 Git、以雜湊確認搬移基線。
2. 建立雙語 agent.md、安全 .gitignore、交接紀錄。
3. 首頁顯示年級 → 年級歌單 → 歌曲練習；不猜測未提供的歌曲。
4. 歌曲合約：年級、歌名、videoId、quizId、15 題、句首/句尾、選項及正解、教師驗收。
5. 保留 YouTube 啟用手勢、片段播放狀態機、停止確認、斷線重試。
6. 核心測試＋導覽瀏覽器測試＋真實影片＋實體 iPad，分別紀錄。
7. Firebase Anonymous / 教師 Email Password / Firestore 規則，部署前確認目標與 Web config。
8. 只有通過驗收的流程才能寫成 Skill；不得把草稿秒數與尚未部署描述為完成。
