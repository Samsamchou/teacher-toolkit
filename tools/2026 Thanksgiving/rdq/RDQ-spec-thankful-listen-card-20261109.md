# RDQ 規格卡：感恩例句聆聽網頁＋感恩節卡片

- status: confirmed
- 日期：2026-11-09
- 模式：Lite（教材／程式）

## 一段式需求規格
做一個 iPad 可開的聆聽網頁，放 35 句感恩例句：7 個對象，每個對象一頁，每頁 5 句，每句旁邊播放現有動畫。學生要把一頁的句子聽完才能翻下一頁；全部聽完後可以往前翻，用 ⭐ 標記想寫的句子，再按「去寫卡片」。另做一張橫式 A4 感恩節卡片 PDF（一位學生一張，左邊填空、右邊畫圖框），加一張詞語庫 A4 參考單。

## 已確認
1. **35 句全用（1A）**：my mom、my grandma、my teacher、my friends、my dog、my school、my family，共 7 頁，每頁 5 句。
2. **插圖（2A）**：直接播放 thankful-35 現有動畫（同一套引擎、配音、卡拉 OK 字幕）。
3. **卡片句子（3A）**：照上台 5 句，再加 To／From。
   - To: ________
   - I'm ________.
   - 文化句（6 選 1）________
   - I'm thankful for ________ because ________.
   - I'm thankful for ________ because ________.
   - 結尾句（6 選 1）________
   - From: ________
4. **網頁功能（建議全採納）**：
   - ① 每句聽完打勾，一頁 5 句都勾了才能翻下一頁；7 頁都聽完會出現「去寫卡片 ✏️」大按鈕，之後可以自由前後翻。
   - ② 每句有「慢速再聽」按鈕（0.7 倍）。
   - ③ ⭐ 標記想寫的句子，最後一頁列出標記的句子，方便抄寫。
   - 進度存在 iPad 本機（localStorage），不收任何學生資料。
5. **卡片（1B、2B、3A）**：
   - 設計採 B「Pippy 彩色版」：橘色雙框、深橘標題列、每行前面有彩色小圖示，右下角站著 Pippy 說 *I'm thankful for you!*（樣稿 `thankful-listen/card/variant_B.png`）。
   - 橫式 A4，一人一張；左邊填空、右邊畫圖框；彩色列印 PDF。
   - 文化句和結尾句由學生自己抄寫一整句（線下有淡色中文提示）。
   - 另外輸出 A3 放大示範卡（②），填入示範稿（Ian：my mom／my friends），畫圖框放對應的插圖，貼在教室或公布欄。
6. **詞語庫（④）**：另做一張 A4 參考單，不放在卡片上。內容：
   - 7 個對象 × 5 個原因。
   - 6 句文化句和 6 句結尾句（含中文）。
   - 可以每桌一張、護貝重複使用，背面空白。
7. **上線（⑤）**：放上 GitHub Pages（teacher-toolkit），發布前先問老師。

## 待確認假設
- 網頁沿用 Ana 的聲音與現有音檔，不重新生成語音。
- 卡片底色用淡奶油色，加秋葉和南瓜線條邊框；黑白印也看得清楚。
- 檔案放在 `tools/2026 Thanksgiving/thankful-listen/`。
