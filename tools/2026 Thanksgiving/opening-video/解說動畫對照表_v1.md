# 開場影片 每句解說動畫對照表 v1（待老師核准）

**播放方式**：每句第一次念播 H3 全畫面 → 翻頁轉場 → 第二次念播**解說動畫全畫面**。

**解說畫面版面**（每張都一樣）：
- 最上方一條：關鍵詞中英標籤。
- 左下角：Pippy 圓框小頭像，從第二次念的 H3 裁出來，嘴形對得上。
- 最下方一條：卡拉 OK 字幕。
- 解說內容放在中間到右邊。

**做法**：
- **程式**：地圖、數字、月曆等，文字一定正確，免費。
- **AI**：Codex 畫首幀，Colab H3 做成無對白特寫動畫。
