## 2. Kurzgesagt 風教學片的做法（四步）

1. **安裝**：一段提示詞叫 Claude Code「用 HyperFrames 幫我設定好，裝好需要的東西，做一支 10 秒測試片」。
   Claude 自己裝好 HyperFrames＋Studio（預覽編輯器）＋Renderer。
2. **先做出一版（「還不夠精緻」）**：描述主題 → Claude 寫 HTML 動畫 → Studio 預覽 → 渲染。
   範例：螞蟻「THAT'S ABOUT 2.5 MILLION ANTS FOR EVERY PERSON」。第一版是普通扁平卡通。
3. **用參考圖「訓練」畫風（關鍵一步）**：丟 5–6 張目標風格截圖，提示詞要它研究
   ①配色 ②飽和度 ③發光效果 ④文字動畫，以及「細節多寡、2D 但有深度」。
   之後同樣的主題（兩隻螞蟻打架，4 秒）就變成深紫夜雨、單一紅色重點、閃電發光、「border dispute／settled in seconds」標籤。
   → **v1 普通卡通 → v2 Kurzgesagt 感，差別只在參考圖＋四個觀察面向。**
4. **聲音（另一半 50%）**：旁白自己錄或用語音 MCP；**音效用 Python（numpy＋scipy）程式合成**（雨聲、撞擊、雷聲）分軌疊上。

**影片的觀點**：「動畫 50%、聲音 50%」；模型做 80% 粗活，人負責參考圖、腳本和一輪輪修正。
作者建議新手**自己上傳配音檔**（時間比較好控制），熟了再讓語音 MCP 自動配音。

**兩支範例片**（逐字稿 `transcripts/kurzgesagt.txt`）：
- 〈閃電〉開場約 1 分鐘（宣稱 40 分鐘做完）。
- 〈打針〉40 秒：模型自己寫腳本 → 人審過 → 語音 MCP 配音 → 動畫＋音效，作者說幾乎全自動。

**Kurzgesagt 式旁白寫法**（可直接借給科普腳本）：
- 第二人稱開場、把觀眾放進現場：「閃電就要打到你了。你站在山丘上……」
- 一個驚人比較：「你肩膀旁的空氣會比太陽表面熱五倍」。
- 「我們來作弊吧」：把一瞬間拉長、一步步拆解，最後**拉遠鏡頭**連到更大的問題。
- 打針那支：同一件事分三種情況比快慢（脂肪→幾小時、肌肉→幾分鐘、血管→幾秒）。這種「一句一個數字」的結構很適合國小科普。

**付費部分**：作者在 Skool 賣「隨插即用系統」檔案；影片已示範免費自建的步驟，**我們不需要買**。

### 我們能借的
- **「參考圖＋四面向」畫風鎖定法**：配色、飽和度、發光、文字動畫。比只寫「Kurzgesagt 風」準很多。
  可直接套到我們 A 類畫風樣張流程。
- **單一紅色重點**（其他都冷色）：跟我們畫風 C 的「一個紅色重點」相同概念，證實有效。
- **科普標籤**：粗體白字＋小副標（如「less than a blink / one strike」），適合自然、社會科的「數字＋比較」。
- **程式合成音效**：免費、可重現，可補我們 A 類影片缺的音效層。

## 3. P(doom) Blender MV 的做法（repo 有完整原始碼）

repo 根目錄 README 寫的七條規則（與我們已有做法高度重疊）：

| 他們的規則 | 我們已有的對應 |
|---|---|
| 每一格只由「歌曲時間 t」決定（不亂數、可平行、可續跑） | ✅ Playwright 逐格截圖、8 段平行渲染 |
| 先寫企劃（概念、畫風、配色、字型、每場景一段）才寫程式 | ✅ RDQ＋逐句分鏡表 |
| 先分析歌曲（拍點、強拍、鼓點、逐字時間），剪接卡在強拍 | ✅ whisper 逐字對時；**拍點偵測可加強** |
| **一場景一檔，平行 agent 各寫一場**；共用引擎只由主 agent 改 | ⚠️ 我們是單一 agent 循序寫，可借 |
| 看格子：總表、連續格、首尾格，一直改到讀得懂 | ✅ 抽格檢查 |
| 每個鏡頭都要有事發生 | ✅ 每句都有對應畫面 |
| 重的離線渲染，必要時租 GPU | ✅ 本機渲染；RunPod 曾評估過 |

### 畫面技法
- **桌上微縮（tabletop miniature）**：整個世界是一張書桌；角色是玩具尺寸（1 單位＝1 公分），
  微距鏡頭淺景深，像真的拍玩具。
- **定格感「on twos」**：角色每 2 格才換姿勢（12 fps），鏡頭與燈光 24 fps 平順——遮掉程式動畫的僵硬。
- **歌詞→桌上道具**：每句變一個桌上物件的小劇場（玩具火車＝訓練、雪景球＝被困住、骨牌＝連鎖、
  迴紋針從一根→一抽屜→整個地球、木頭織布機、劇院布幕）。和我們「歌詞→比喻道具」同一套思路。
- **貫穿全片的儀表**：桌上黃銅 P(doom) 表，每唱到 DOOM 指針跳一格（25→50→75→100 玻璃裂開）。
  → 可借成「進度／情緒儀表」，例如「好心情指數」。
- **物理模擬**：數千根迴紋針雪崩、碎裂、煙、液體、骨牌——Blender 獨有，網頁 Three.js 做不到這麼真。
- 收尾：研究員和 AI 坐在紙月亮上看迴紋針地球（溫柔結尾）。

### 成本與門檻
- 需安裝 **Blender 5.2**（免費，本機目前沒有）＋約 110 MB CC0 貼圖。
- 1080p／24fps：一格約 1–5 秒（作者用 RTX 5090）；我們筆電沒有獨顯的話會慢很多，**要先實測**。
- 4K60 最終版他們租雲端 GPU；我們課堂用 1080p 就夠，不必租。
- ENGINE.md 列了約 40 條 Blender 5.2 的踩坑（燈光瓦數、景深單位、模擬快取、能見度關鍵影格…），
  若要做，可以直接當我們的踩坑表起點。

## 4. 回答：Opus 5.5（我）做得出來嗎？

### Kurzgesagt 風——**可以，而且門檻低**
- 技術上就是「HTML／SVG／Canvas 程式動畫＋渲染成 MP4」，跟我們 A 類流程同一類（我們用 Canvas＋Playwright；
  HyperFrames 是把這件事包裝好的開源工具，可選用）。
- 真正決定像不像的是**畫風鎖定**：參考圖＋配色／飽和度／發光／文字動畫四面向，這我們可以做成畫風 G 樣張。
- 注意：「Kurzgesagt 風」是借**風格語彙**（扁平向量、夜色、發光、單一重點色），不複製他們的角色、
  鳥吉祥物或片頭；我們用自己的角色（科幻雙老師、六位學生）。
- 適合：自然科、社會科、在地課程的科普短片（例：「二水的濁水溪有多長？」「一顆米從稻田到便當」）——
  數字比較、剖面圖、地圖縮放正是這種畫風的強項。
- 和 A3 旁白式影片的差別：A3 用 AI 插圖＋程式字卡；這個是**全向量程式畫面**，不必生圖、不花錢、角色永遠一致。

### Blender 桌上微縮——**可以，但比較重**
- repo 證明 Opus 5.5 能寫完整 Blender 管線（建模、骨架、物理、燈光、渲染）。我們有 repo 原始碼（MIT）可當引擎起點。
- 我們已經有 Three.js 3D（畫風 E）和 Tripo 模型（A5），Blender 的優勢是**真實光影、景深、物理模擬**，
  質感接近定格動畫電影。
- 門檻：要裝 Blender、本機渲染速度未知、一支 2–3 分鐘片子工作量是我們 A1 的好幾倍。
- 建議：先做 **10 秒試片**（一張書桌、一個我們自己的玩具角色、一個道具動作），量本機每格秒數，再決定值不值得。
