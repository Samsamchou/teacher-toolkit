## 二、片子結構（定案版）

1. **冷開場**（約 7 秒）：臥室鏡子 → You wake up. You look in the mirror. / Huh? You are Ken!
2. **片名**：WHAT IF YOU WERE / KEN IN ERSHUI?（車站夜景＋光束）
3. **設定**：It's spring break. No classes for seven days!（七張月曆一張一張跳出）
4. **11 個情境**，每個情境：
   - **問句（2D）**：問的人（左）＋Ken（右）站在背景前。It's <星期>. It's <天氣> today. It's <時間>. Where are you going?
     DAY／TIME／WEATHER 三個大標籤**在念到那個字時**跳出來。
   - **線索 2.5 秒**：畫面變暗＋Listen!（環境聲）或 Look!（兩個遊戲圖示）。老師可暫停讓學生猜。
   - **答句（3D，5.8 秒）**：Ken 走到建築門口轉向鏡頭。I'm going to the ___. I want to ___.
   - **串場句（2D，旁白）**：把下一天接起來（火車、信、球被風吹走、打噴嚏、看醫生……）。
5. **結尾**：博物館老火車＋書本小圖 → 一週回顧（11 張 3D 縮圖照星期飛入）→ WHAT A WEEK! → 回到片名＋大問號。

## 三、技術流程

```
遊戲題庫 JSON → RDQ → 故事稿（Google 文件）→ voices.json → make_voice.py（edge-tts＋逐字時間）
     → Codex 生圖（queue.py，最多同時 3 張）→ cutout.py 綠幕去背
     → film.js 時間軸（秒數由配音長度自動排）→ render.py still／sheet 檢查
     → b3d_shot.py（Blender 5.2）→ colab_3d.py 在 Colab G4 一鏡一批 → renders/3d/<鏡>/f0000–f0139.png
     → render.py video（字幕版）／--nokara（聽力版）→ ffmpeg 720p
```

- **2D 引擎** `film.html`：canvas 每格只由時間 t 決定（`renderAt(t)`）。工具函式：cover（鋪背景）、char（立牌＋輪廓光＋影子）、camAt／withCam（推拉＋震動）、rain／leaves／bokeh／rays／puffs、bigText（漫畫大字）、calendar、listenIcon／lookIcons、kara（卡拉 OK）、hud（大標籤）。
- **時間軸** `film.js`：`scene({...})` 一行一個情境；`link.draw` 寫串場畫面；`clueLen`／`clueFile` 改線索長度；`cap: {x, top, maxw}` 搬字幕；`F.duck` 讓背景音樂在長線索時變小。
- **3D** `b3d_shot.py`：`SHOTS` 表（建築、高度、天氣、道具、旋轉、`run`）；`PLATE` 蓋住拼錯或品牌招牌；窄店面自動加無字鄰居房子；`ARM` 表（上臂、前臂、手指方向、掌心方向、彎指）；`hand_frame` 從真實手指骨頭算手掌座標放道具。
- **渲染** `render.py`：still／sheet／video／preview（只輸出指定秒數段落）；混音支援 loop 與閃避；-16 LUFS。

## 五、踩坑與修法（照發生順序）

1. **Codex 不能寫 G 槽** → 在 `C:\Users\User\whatif-ken-work\gen` 生圖再複製；Codex 沒存檔就從 `~/.codex/generated_images` 撈。
2. **綠幕去背吃掉綠色衣服**（水鈴綠裙半透明）→ cutout v2 只去「接近純綠 #00FF00」。
3. **edge-tts 連線逾時** → make_voice.py 自動重試 4 次；已生成的句子跳過。
4. **Ken 3D 變粉紅金屬** → 外部貼圖（basecolor／normal／rm）要一起上傳；材質改 metallic 0、roughness 0.7。
5. **地上白色方塊反光** → 門口燈 `visible_glossy=False`。
6. **拍到 Ken 背影** → 鏡頭放 Ken 右前方 3/4，Ken 在畫面左 1/3。
7. **招牌拼錯（DUIMRINGG）、品牌字（TEA TOP）** → `PLATE` 蓋色板＋正確英文（DUMPLING、TEA SHOP、SUPERMARKET）。
8. **窄店面看起來空** → 兩側自動加無字鄰居房子＋人行道。
9. **博物館側著** → `rot=90`。晴天地面過曝 → 降 sun／world 強度。
10. **Colab G4 常 Service Unavailable** → 自動重試 5 次；`GPU=L4` 可換卡。
11. **10 鏡同一批跑 2 小時 13 分，Colab 把 session 結束，圖全沒了** → `work/run_pershot.sh` 一鏡一批、渲完立刻下載、少格重渲一次、最後自動關機。
12. **Colab exec 卡住（狀態 IDLE、0 格）** → 每鏡最多等 25 分鐘；同一台連續卡兩次就 stop 換新機器。渲染中不要另外 `colab exec` 查進度，用 `colab ls`／`colab status`。
13. **字幕擋住中間的火車站**（老師 v1 回饋）→ 下方字幕一律放最下緣（bottom 28px）；擋到主角的段落另設 `cap: {x}` 移到左下。
14. **信插進手裡、球抱在胸前、風箏橫過身體**（老師 v1 回饋）→ 手要「真的拿住」：`aim(骨頭, 方向, 掌心方向)` 會轉掌心；道具位置用 `hand_frame` 的真實手掌座標算。信＝捏在拇指與食指間、信露在手外；球＝單手掌心向上托在肩旁；風箏＝手掌張開夾住下方竹骨、風箏直立在身旁。**每個手拿道具的鏡頭先渲手部特寫自己看過再渲正式。**
15. **「You run and run」Ken 用跳的**（老師 v1 回饋）→ 2D 立牌上下彈不像跑 → 改 3D 跑步鏡 `s03run`。模型只有 walk／idle；把走路放大會像踢腿、而且走路動畫是原地的（stride 0）→ 用骨頭角度程式做跑步（大腿擺 32°、收腿膝蓋折 107°、手肘 90° 反向擺、身體前傾、腳貼地、速度由腿長算）。
16. **博物館線索聽不出來**（老師 v1 回饋）→ 線索聲用遊戲原檔完整播完（18 秒），播的時候背景音樂 -12 dB、Listen! 一直顯示。
17. **影片檔 >30 MB 傳不到手機** → 只交 1080p＋720p，請老師在桌面版看；或給 Google 雲端硬碟網址（G 槽自動同步，預設私人）。
