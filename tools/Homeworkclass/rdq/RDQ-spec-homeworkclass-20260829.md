# RDQ 需求規格：Homeworkclass 教師作業與課堂紀錄網站

## 一句話任務
在 **Homeworkclass** 建立單一教師使用的 Firebase 響應式網站，以週課表快速記錄八班作業、繳交／補交與課堂事件，並提供跨週查詢、需關注提示及可攜式匯出。

## 已確認
- 根目錄為 **G:\我的雲端硬碟\teacher-toolkit\tools\Homeworkclass**；沿用父層 Git 儲存庫，只處理本資料夾。
- 班級為 **六甲、六乙、五甲、五乙、四甲、四乙、三甲、三乙**；採多巴胺配色、響應式版面，班級各有不同顏色並同時顯示文字／圖示。
- 教師由首頁右上角「教師後臺」進入，只輸入 **6 位數通行碼**；不使用 Google 帳號登入、不提供學生或家長入口。
- 通行碼由後端驗證並簽發固定教師身分，搭配失敗限制、App Check 與預設拒絕的 Firestore Rules；通行碼不得寫入前端、Git 或本規格卡。
- 登入時可選私人裝置：共用裝置閒置 **30 分鐘**登出，私人裝置保留 **7 天**，並提供手動登出。
- 功能 1：以週一至週五完整課表為主體，包含英語、在地、國際歌謠；點日期／節次後帶入科目與班級，作業類型為課本、習作、線上練習／學習單、小考，另輸入內容並保存出題日期與節次。
- 功能 2：先選班級，再顯示該班前 **5 個實際上課日**所出作業，可跨週且涵蓋英語、在地、國際歌謠；較舊但仍未補交者另列且不消失。以座號狀態為準，一鍵全班已交後設定例外，自動計算已交／未交人數。
- 未交資料拆為原因（請假、無故、其他）與結果（仍未交、當天完成、日後補交）；補交保留事件與實際日期，不覆寫原始狀態。
- 功能 3：依日期／節次／班級記錄上課遲到、上課聊天、不守秩序、未帶課本／習作／文具，可填座號與簡短事實紀錄。
- 功能 4：可依週、跨週、班級或座號查詢作業、繳交、補交及課堂事件；匯出 CSV、XLSX 與可列印週摘要，並支援備份與還原驗證。
- 「需關注」預設權重為遲到 1、聊天 1、未帶用品 1、不守秩序 2；每週達 **4 分**才提示，門檻可調，須由教師確認，不自動貼負面標籤。
- 僅保存本學期及前一學期；只使用班級與座號，不保存姓名、正式學號、家長資料或敏感輔導資訊。
- 網站顯示名稱為「**英語作業與課堂紀錄**」；時區採 **Asia/Taipei**，校週以週一至週五顯示。
- 課表採學期版本與有效日期，可登記停課、調課及補課；「實際上課日」是該班確實上英語、在地或國際歌謠且可出作業的日期。
- 通行碼預設連錯 **5 次鎖定 15 分鐘**；教師在部署時親自設定或更換秘密值。
- 超出兩學期的資料先提示匯出，再由教師手動確認刪除；第一版不自動破壞性刪除。
- 技術基線採 React、TypeScript、Vite、Firebase Hosting、Authentication 自訂權杖、Cloud Functions、Firestore、App Check。
- Firebase 目標專案由教師提供為 **hwclass-479d2**；此項只記錄指定目標，不代表已登入、驗證設定、啟用計費或部署。
- 本學期有效期間為 **2026-08-31（週一）至 2027-01-20（週三）**，起訖日均納入。
