# RDQ 需求規格：方塊體素風聖誕繪本（3D 影片＋2D 朗讀字幕版）

## 一句話任務
以 HESS 聖誕網站 8 幕故事為基準，寫一份含 8 個指定單字的五六年級故事稿，做成 3D 方塊體素繪本影片，再做一支只有卡拉 OK 字幕、無配音的 2D 版給學生在全校面前朗讀。

## 已確認
- 來源：https://kingwolfe01-hub.github.io/hess_Christmas_code/ 的 `js/story.js` 8 幕（台灣冬日校園→冒險背包→聖誕傳送門→時空隧道→北歐暴風雪→救馴鹿→木屋壁爐→聖誕派對）；錄影 `參考/麥塊繪本.mp4`（2:28）。
- 8 個單字各在一個不同句子、一句不放兩個：**Christmas tree、a star、a stocking、a reindeer、a snowman、a candy cane、a gift、Santa**。
- 有開頭、起伏、結尾；五六年級看得懂。
- 主角：**Ken＋水鈴（Shuiling）方塊版＋Santa**（1A）。
- 長度：**8 幕 × 3 句＝24 句**，朗讀約 2.5 分鐘（2B）。
- 3D 版：**英文配音 0.8 倍＋卡拉 OK 字幕**，另出**無字幕聽力版**（3C）。
- 全校朗讀日期：**12/19–12/25**（4B）。
- 2D 版：純程式＋3D 建模、只有卡拉 OK 字幕、不配音；學生朗讀完再播 3D 版。
- 畫風：新畫風 **K 方塊體素繪本**（畫風 E 的 Three.js 引擎＋程式方塊拼人物與場景，不用 Tripo），本機渲染。

## 已採納建議（5 項全採納）
1. 不用 Steve、Alex、苦力怕、地獄門與 Minecraft 名稱／材質；傳送門改冰晶＋星星造型。
2. 2D 版做成網頁播放器（空白鍵換下一句、卡拉 OK 依設定速度），另交 MP4。
3. 單字句出現時，角落跳出單字大圖卡（圖示＋大字）。
4. 動工前先做 YouTube 方塊風 3D 動畫參考研究報告（只學手法）。
5. 教材規則 v2 包本次不做。

## 待確認假設
- 8 個單字以外的句子可以再提到單字（例如 Santa 說話），但一句最多一個。
- 3D 配音：旁白＋Ken／水鈴／Santa 各一個聲音；配樂 −18 dB。
- 故事稿放 Google 文件給老師改。
- 英文字一律 Comic Relief、字幕往上 56 px；交 1080p＋720p，不做手機版。
- 2D 版 MP4 的每句秒數＝3D 配音秒數 × 1.5（學生唸得比配音慢）。

## 本次不納入
- 教材規則 v2 包（簡報、字卡、學習單、Kahoot）。
- AI 生成影片鏡頭（KIE／Colab H3），除非之後另外報價。

## 一段式需求規格
以 **https://kingwolfe01-hub.github.io/hess_Christmas_code/** 的 8 幕聖誕冒險為骨架，改寫成 **24 句**（每幕 3 句）、五六年級看得懂的英文故事稿，主角為二水 IP 的 **Ken** 與 **Shuiling**（方塊版）加上 **Santa**；**Christmas tree、a star、a stocking、a reindeer、a snowman、a candy cane、a gift、Santa** 各放在不同句子，一句最多一個，故事要有開頭、危機起伏與溫暖結尾，稿子放 Google 文件由老師核准。核准後先完成 YouTube 方塊風 3D 動畫參考研究報告，再以新畫風 **K 方塊體素繪本**（Three.js 程式方塊拼人物與場景，不使用 Minecraft 角色、怪物、地獄門或名稱）做一張樣張與一幕試片給老師核准，接著做 3D 全片：英文配音 0.8 倍、Comic Relief 卡拉 OK 字幕（往上 56 px）、單字句角落跳單字大圖卡，輸出**字幕版＋聽力版**，各有 1080p 與 720p。之後用同一組方塊模型做 2D 版：只有卡拉 OK 字幕、無配音，做成按空白鍵換句的網頁播放器並另交 MP4，供 **12/19–12/25** 全校朗讀使用。

## 驗收條件
- [ ] 故事稿：24 句、8 個單字各在不同句子且一句不超過一個，老師核准。
- [ ] 3D 版：每一句都有對應畫面；角色與場景全原創；字幕版與聽力版老師看片驗收。
- [ ] 2D 版：網頁播放器在教室投影上用空白鍵換句試過一次；MP4 速度跟得上學生朗讀。
- [ ] 全部在 **12/18** 前交件，留時間給學生排練。
