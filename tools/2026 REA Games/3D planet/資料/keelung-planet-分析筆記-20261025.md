# 基隆小行星（Keelung Planet v0.14.3）試玩與技術分析（2026-10-25）

來源：22 分鐘錄影的 250 張截圖（本資料夾 Snapshot_*.png）、在內建瀏覽器實際進入遊戲、讀取網站公開載入的 JS 檔開頭註解。沒有下載或複製對方程式碼。

## 試玩結果
- 實際操作：進入冒險、開任務清單（共 39 項）、自走（R）、摸狗（E）、開「請小天使帶路」選單。
- **沒有完成任何任務**：內建瀏覽器工具只能「點按」鍵盤，不能按住方向鍵，角色在騎樓卡住；小天使帶路要 5 顆小太陽，手上只有 3 顆。
- 任務流程改以錄影補足：錄影中完成約 14 項（陸橋、正濱彩色屋、燈塔、廟口拜拜、騎機車、外木山步道、騎腳踏車、慶安宮求籤、田寮河白鷺鷥、主普壇、KEELUNG 字等）。

## 39 項任務分類（從任務清單讀到）
- 走到地標（陸橋、海洋廣場、KEELUNG 字、基隆塔、主普壇、大觀音、正濱、外木山涼亭…）
- 時間／天氣條件（晚上看燈塔、下雨走陸橋、黃昏拍夕陽、晚上猜燈謎）
- 交通工具距離（機車 100 m、腳踏車 200 m、游泳 20 m）
- 收集與計數（廟口 5 種小吃、和街坊打招呼 4 人、特產 20 種、小太陽 208 顆、羽毛 5 根）
- 小遊戲（慶安宮求籤、猜燈謎、夜市遊戲、外送、望遠鏡）

## 技術架構（從 JS 註解讀到）
| 項目 | 做法 |
|---|---|
| 引擎 | three.js 0.170（CDN），約 75 個 ES module、合計約 1.8 MB JS，**沒有任何 3D 模型檔** |
| 星球 | 半徑 R = 40（周長約 251 m）；UV 球依 `heightAt()` 隆起做山城地形 |
| 道路 | 每條路是球面上約 0.5 m 一點的取樣線；路面是貼地網格條帶；斑馬線、中線、紅線在 shader 裡依「離路口距離」畫，並查過交通標線規則 |
| 街景 | `city.js` 沿道路兩側自動擺透天厝（主街有騎樓），再補第二排；固定種子亂數，每次一樣 |
| 合併 | `kit.js` 把大量方塊／圓柱寫進一個 Float32Array（頂點色），整條街分 8 塊網格，畫得快 |
| 碰撞 | 切平面矩形方塊（gnomonic 投影）＋底／頂高度，可做樓梯、天橋 |
| 畫風 | Toon 材質＋後製描邊：顏色 pass、法線 pass、全螢幕合成，做出手繪黑線 |
| 角色 | `doll.js` 程式組出的玩偶，不用骨架：走路＝腿前後擺、手反向擺 |
| 日夜 | 一輪 240 秒；天空四色、太陽、海面顏色、窗戶發光依關鍵影格插值 |
| 天氣 | 每 3–5 分鐘下雨 40–90 秒；雨絲 shader、地面變濕與水窪 |
| 首頁 | 低空空拍：8 字形一筆畫路線、鏡頭朝前進方向看、高度取附近平均避免點頭 |
| 任務 | 資料驅動（quests.js 純資料欄位 id/text/of/when/count/story/hidden），判斷在 tasks.js |
| 移動 | 撐傘「降落」瞬間移動：鏡頭從太空俯衝 → 開傘 → 鐘擺落地（寫好的動畫，不跑物理） |
| 帶路 | 小天使沿道路中心線 A* 找路，轉彎處閃亮點 |

## 製作方法的線索
- 註解大量出現「使用者 2026-10-0X 決定」「企劃第 N 節」「版本更新紀錄.md」→ 作者用 Opus 逐版迭代，每個決定寫進企劃與版本紀錄（和本專案 RDQ＋HANDOFF 的做法相同）。
- 地標都先查實景（Wikimedia Commons 照片、OSM、維基），再用程式方塊重現特徵，招牌只寫品項。

## 對二水版的啟示
- 球面路網＋程式街景＋toon 描邊，是做出「小行星」感的核心，不靠模型。
- 二水版依規格：Godot 實作同樣的球面投影、程式街景與描邊後製，地標改用 Tripo 模型，招牌字用 Label3D。
