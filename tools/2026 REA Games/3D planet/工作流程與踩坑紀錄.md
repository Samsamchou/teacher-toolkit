# 3D Planet 二水小行星：從 0 到現在的工作流程與踩坑紀錄（2026-10-25）

> 目標：仿「基隆小行星」，做一顆可以俯瞰、街道照真實二水復刻的小星球，讓 5–7 組學生押注猜角色要去哪裡，練地點單字與 Where … going? / Where's the __? 句型。

## 一、整體工作流（照順序）

### 1. 研究參考作品（基隆小行星）
1. 老師用 FonePaw 錄了 22 分鐘遊戲影片，但沒付費不能匯出檔案。
   - 做法：Computer Use 操作 FonePaw 播放器，**連續播放、每約 5 秒按一次「相機」快照鈕**，共 250 張 → `資料/Snapshot_*.png`。
   - 再用 Python 拼成帶時間標籤的縮圖表逐張看，整理出時間軸內容。
2. 在瀏覽器打開網站，用 JavaScript 讀「網站實際載入的檔案清單」與每個 JS 檔開頭的註解（不複製程式碼），得知架構：three.js、約 75 個模組、**完全沒有 3D 模型檔**、球面投影、程式街景、Toon＋描邊後製、資料驅動任務。→ `資料/keelung-planet-分析筆記-20261025.md`
3. 嘗試在內建瀏覽器實際玩：只能「點按」鍵盤、不能按住方向鍵，角色卡在騎樓，**沒有完成任何任務**；改以錄影＋程式註解分析。

### 2. RDQ 釐清需求（兩次）
- v1：技術（Godot＋延伸既有二水路網）、5 套題組、吉祥物、部署方式、5 項建議全採納 → confirmed。
- v2：老師 iPad 試玩後提出 6 點 → 第二次 RDQ（照片來源、Road/Street 規則、顏色是否固定、林先生廟是否出題）→ confirmed。

### 3. 查證地點與角色設計（子代理背景研究，只寫文字不存圖）
- `資料/research-ershui-places-and-mascot-20261025.md`：11 個單字各對到真實地點（hospital 用衛生所）、寶可夢設計方法 7 條、吉祥物方案。
- `資料/research-ershui-streetscape-20261025.md`：二水街屋類型（紅磚洋樓、洗石子公館、磁磚透天、老店屋、日式宿舍）＋建模參數。
- `資料/research-destination-buildings-20261025.md`：22 處目的地的最新外觀＋建模提示詞；老師補的 Google 地圖連結（五分田、大盟書局、源泉國小、郵局、衛生所）也記在最後。

### 4. Godot 專案（`godot-ershui-planet/`，Godot 4.7.2，GL Compatibility）
- **地圖資料**：`tools/fetch_osm.py downtown|southeast` 下載 OpenStreetMap → `tools/build_osm_map.py` 轉成 `data/map.json`、`data/sets.json`。
  - 真實 1 m → 遊戲 0.55 m；市區取車站周邊 460 m；東南街區（二水國中、源泉國小、林先生廟）與八堡圳公園各自照真實街道，但**和市區之間的距離壓縮**，用聯外道路接起來。
- **球面**：所有東西先在平面組好，再用方位等距投影把每個頂點彎到半徑 R=280 的球面（`world.gd` 的 `bend()`）；找路、走路都在平面算。
- **街景**：OSM 549 棟建築照真實輪廓長高，臨街面依樣式加騎樓、鐵捲門、鐵窗、立招、水塔、鐵皮加蓋、紅磚拱窗等；電線桿＋電線、圳道、鐵路與集集線小火車。
- **地點建築**：22 處用 Tripo 復刻模型 `assets/models/bld_<id>.glb`，中文招牌用 Label3D 疊。
- **角色**：Ken（舊 Tripo 綁骨模型）、水鈴、圳寶（這次 Tripo 圖生 3D → 綁骨 → walk 動畫）。
- **玩法**：首頁空拍 → 選 5–7 組＋科幻 emoji → 選人物模式（6 種）→ 選路線（5 套）→ 押注 → Start → 角色沿真實路網走 → 抵達揭曉、猜對 +2 → 必須按「聽句子」才能 Next → 結果頁。右上：地圖、快轉、音量、再聽、保留、首頁。
- **聲音**：edge-tts 0.8 倍速 80 句（`tools/make_voice.py`）、Kenney CC0 音效、Suno 原創 BGM。
- **自動測試**：`Godot_v4.7.2-stable_win64_console.exe --path . -- --test`，環境變數 `MODE=ken|zunbo|yuyu|mix|we|where`、`SET=0..4`、`ARRIVALS=1`（只拍 21 站抵達檢查表，再跑 `tools/arrival_sheet.py`）。

### 5. 生圖（Codex CLI）
- 12 個組別 emoji（一張 4×3 表 → `tools/slice_emoji.py` 依白色間隙切圖）、吉祥物 3 款＋水鈴 A-pose、22 張建築參考圖（`scratchpad/gen_buildings.py`，4 個同時跑）。
- 提示詞與 SHA-256：`資料/generated-images/provenance.json`、`資料/generated-images/buildings/provenance.json`、`資料/building-prompts-20261025.json`。

### 6. Tripo（Chrome 已登入的 Tripo Studio）
- 設定：HD Model、H3.1、Triangle、**10000 面**、4K PBR、Private。每個 55 點。
- 角色：生成 → （面數太多才 Retopo 35 點）→ Rig 20 點（Humanoid、Mixamo 骨架）→ Animate 搜「walk」preset（免費）→ 匯出 GLB 勾 walk、In Place。
- 建築：一張一張上傳 → Generate；全部發出後再到每個 task 頁面 Export（GLB、2K）。task 編號記在 `資料/tripo-buildings-20261025.json`。
- 點數：3000 → 2740（吉祥物）→ 1475（建築 22＋重做 1）。

### 7. 網頁匯出與部署
- 匯出 `../web-build/`（目前 pck 52.1 MB、wasm 37.7 MB）→ 複製到 `escape room HWG5-U01-U02/site/public/ershui-planet/` → `firebase hosting:channel:deploy ershui-planet --expires 7d --account u9431818@gmail.com`。
- 預覽網址：https://hwg5-clock-tower--ershui-planet-macshnp6.web.app/ershui-planet/ （**正式站 live 沒動**）。

## 二、踩過的坑（症狀 → 原因 → 解法）

### 影片與瀏覽器
| 症狀 | 原因 | 解法 |
|---|---|---|
| 螢幕截圖看不到 FonePaw 的影片畫面（黑／灰） | 播放器畫面不被螢幕擷取 | 用播放器自己的「快照」鈕，連續播放每 5 秒按一次 |
| 內建瀏覽器玩不動基隆小行星 | 只能點按鍵，不能按住方向鍵 | 改用錄影＋網站程式註解分析 |
| 內建瀏覽器打不開 share.google 短網址 | 被拒絕導覽 | 改用老師的 Chrome（Claude in Chrome） |
| Tripo 分頁截圖逾時、畫面凍住 | 3D 頁面長時間開著 | 關掉分頁、開新分頁重來 |
| 預覽伺服器開到別的專案 | preview 讀的是 session 根目錄的 `.claude/launch.json`，8765 埠被別的設定佔用 | 在 `2026 REA Games/.claude/launch.json` 加 `ershui-planet-web`，用 8791 埠 |

### Godot／GDScript
| 症狀 | 原因 | 解法 |
|---|---|---|
| `Cannot infer the type of "x"` 一直出現 | 從 Dictionary／Array／Callable 取值時 `:=` 推不出型別 | 明確寫型別：`var x: float = ...`、`for sg: float in [...]` |
| 測試跑到一半卡住不結束 | 腳本 Parse Error 時 Godot 不會自己關 | 先跑 `--headless --quit-after 3` 檢查，再跑完整測試；卡住就 `Stop-Process Godot*` |
| 程式產生的房子全黑 | 三角形繞向反了，描邊外殼把房子蓋住 | `FLIP := true` |
| 房子只蓋出 1～23 棟 | 重疊檢查用對角線半徑，同一條街相鄰房子全被判重疊；房子後退距離又剛好壓到路邊判定 | 只檢查不同街道的房子；後退距離加 0.2 m |
| 臨街面的細節貼到背面 | OSM 輪廓反轉後，外側法線方向算反 | `nrm = Vector2(-u.y, u.x)` |
| Python 腳本寫 world.gd 後 Godot 讀不到 | PowerShell `Set-Content -Encoding utf8` 會加 BOM | 用 `[IO.File]::WriteAllText(..., UTF8Encoding($false))` |
| 一段 `print` 被黏到上一行導致 Parse Error | PowerShell 字串取代時少了換行 | 改完一定跑 parse 檢查 |
| 網頁版 pck 160 MB | Tripo 貼圖 4K 原封不動匯入 | `tools/shrink_textures.py`：底色 768、粗糙度 256、法線 512、Basis 壓縮 |
| 新模型後 pck 68 MB | 用不到的舊模型也被打包 | `export_presets.cfg` 的 exclude_filter 排除舊 GLB；復刻建築貼圖 768 → 52 MB |

### 鏡頭與畫面
| 症狀 | 原因 | 解法 |
|---|---|---|
| 抵達圖書館時看不到 Ken、也看不到整棟 | 鏡頭距離固定、前排房子擋住 | 距離依建築大小；在建築四周找最不被擋的角度（`arrive_view`）；中間的街屋方塊變半透明 |
| 大盟書局前面一整面牆不透明 | 方塊的半透明範圍用固定格子大小，實際房子跨格 | 範圍改用每格房子的真實外框；鏡頭 16 m 內也變透明 |
| 7-ELEVEN、書局鏡頭下方被屋頂塞滿 | 鏡頭剛好在屋頂上方 | 「鏡頭正下方 3 m 內有屋頂」算擋住，換角度 |
| Ken 描邊太粗認不出來 | 模型描邊用統一粗細 | 角色描邊 0.3 倍 |
| 吉祥物黑線穿過頭髮 | 同上，細節多的模型更明顯 | 同上 |
| 中文招牌太大蓋住建築 | 字的大小依建築寬度、位置固定 | 寬度約建築 45%，高度依每棟英文佔位招牌位置（`SIGN_Y`） |
| iPad 上 Set 2–5 看起來選不到 | 點完按鈕停在 hover/pressed 樣式，蓋住「已選」綠色 | `_paint()` 四種狀態都換色；Go 按鈕寫出選了哪套 |
| 設定頁在 720p 被切掉 | 加了人物模式後太高 | 改成可上下捲動 |

### 地圖資料（OSM）
| 症狀 | 原因 | 解法 |
|---|---|---|
| Overpass 回 406 | PowerShell Invoke-WebRequest 標頭 | 改用 Python urllib，加 User-Agent |
| 輸出中文亂碼 | Windows 主控台編碼 | `$env:PYTHONIOENCODING="utf-8"` |
| 外圈地點全擠在同一方向 | 照真實方位，彼此太近 | 依序推開至少 18 度，再整體移回 |
| 東南地點的門口連不到路 | 街區半徑太小切掉道路 | 東南街區 290 m、市區 460 m；每個街區各留最大連通塊，再用聯外道路接 |
| 五分田和鄭鼎宅落在同一棟 | 找最近建築時沒排除已被使用的 | `find_building` 排除 `removed`；五分田排在老建築之後處理 |
| 新開的店 OSM 沒有輪廓 | OSM 還沒畫 | 程式在門口後面自動做 5×8 m 的店面 |
| 清心福全 Google 地圖查不到 | 可能已歇業 | 老師指定改成五分田-二水光化店 |

### 生圖（Codex）
| 症狀 | 原因 | 解法 |
|---|---|---|
| Codex 說存好了，但 G 槽沒有檔案 | Codex 沙箱不能寫 G 槽 | 到 `C:\Users\User\.codex\generated_images\` 撈最新的 PNG；之後一律先輸出到 scratchpad 再複製 |
| `codex exec -i 圖 "提示"` 沒反應 | `-i` 會把後面當成圖片清單、提示詞被吃掉 | 提示詞放前面、`-i` 放最後 |
| emoji 表切到隔壁 | 平均切格不準 | 依白色間隙找格子邊界 |
| AI 招牌中文字錯（例：水心之初→冰心之助） | 生圖模型寫中文不可靠 | 參考圖一律用英文佔位字，遊戲內疊 Label3D |

### Tripo
| 症狀 | 原因 | 解法 |
|---|---|---|
| 水鈴第一版走路時頭髮歪掉 | 雙手捧鈴、手貼身體，自動綁骨分不清 | 用 Codex 重畫 **A-pose**（手張開、鈴掛腰上）再做 |
| 吉祥物只有 walk 動畫，停下時姿勢怪 | 匯出只勾 walk | 停下時停止動畫並把骨架重設回綁骨站姿 |
| 匯出檔落成 `.tmp` | Chrome 下載行為 | `scratchpad/grab.ps1` 等檔案大小穩定、檢查 `glTF` 開頭再改名；中文路徑要用參數傳 |
| 按 Generate 沒有扣點 | Tripo 同時生成數量有上限 | 每次看點數有沒有減少，沒減就再上傳再按 |
| 二水國中做出來是一片皺紙 | 參考圖有透空走廊與曲面陽台 | 免費重試也一樣 → 重畫「實心」版本再做 |
