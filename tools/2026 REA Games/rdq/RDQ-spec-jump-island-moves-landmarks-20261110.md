# RDQ 需求規格：Jump Island 地標＋華麗動作＋音效

## 一句話任務
讓 Jump Island 每關都有二水地點特色（建築模型＋專屬終點門），Ken 有真正的跳躍動畫和 Super Mario Run 式華麗動作，搭配免費授權音效；先做第 1 關給教師 iPad 試。

## 已確認
- **1C**：每關路線旁放**該地點的二水建築模型**（沿用二水 3D 闖關的 bld_*.glb）＋起點大地名招牌＋**專屬終點門**（例：火車站＝剪票口、國小＝校門）；建築進到該關才下載，遊戲檔不變大。
- **2B**：到 Tripo 幫 Ken 加真正的**跳躍動畫**（重新綁骨或選預設動作），再加程式做的翻滾、旋轉；需要教師在 Chrome 開 Tripo 配合；花點數前先說明點數與餘額並等教師同意。
- **3C**：Super Mario Run 全套：自動翻身跨越（翻的時候點一下跳更高）、踢牆跳、空中再點一下旋轉、連續踩史萊姆跳出 **Nice / Great / Excellent!**；**踢牆跳從第 4 關才出現**，第 1 關維持教學關。
- 音檔爆音已修好（雙層檔頭造成，14/14 字辨識正確），隨下次預覽部署上線。
- 不使用任天堂任何畫面、音效、名稱或程式碼。

## 待確認假設
- 第 1–11 關建築對應：火車站、驛站、便利商店、國小、飲料店、二水超市、郵局、書店、超市、圖書館、農情館；魔王關用水公園、大草原的場景模型。
- 終點門用程式方塊＋Kenney 素材組合（不再用 Tripo 生成新模型、不花點數）。
- Tripo 若找不到合適的跳躍預設動作，退回全部用程式做動作，先回報再改。
- 金幣、華麗動作計數都不算分數；音效音量比背景音樂小、答題時降低。

- ② 路上放**金幣**，吃到「叮」一聲、上方顯示金幣數。
- ③ **先做第 1 關**（含火車站地標、剪票口終點門、全部動作與音效），教師 iPad 試過再套到其他 12 關。
- ④ 過關畫面顯示「華麗動作」次數。
