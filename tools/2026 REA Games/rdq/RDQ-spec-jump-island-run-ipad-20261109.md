# RDQ 需求規格：Ken's Jump Island → iPad 自動跑版（SF3 小考）

## 一句話任務
把 Jump Island 從「搖桿＋按鈕的 3D 自由移動」改成 Super Mario Run 式「自動往前跑、點螢幕就跳」的側面 2.5D 闖關，題目換成 SF3 四年級讀寫小考，並套用二水 3D 闖關的 iPad 修正。

## 已確認
- 玩法 **1A 側面 2.5D 自動跑**：Ken 自己往前跑，**點一下小跳、按住跳更高**；鏡頭從側面看；碰星星出題（星星＝題目）。
- **2A 橫拿 iPad**（題目畫面沿用現在的排版）。
- **3A 掉下去**：泡泡包住 Ken、飄回前面一點繼續跑，不扣分、沒有 Game Over。
- 題目：**SF3 四年級 期中範圍 讀寫小考，17 題、100 分，題型和題數不變**（看圖排字 10、Read and Match 2、對話填空 5），來源 `English exam/.../output/SF3_小考_期中範圍讀寫_20261101/_紀錄/quiz_items.json` 與 15 張圖。
