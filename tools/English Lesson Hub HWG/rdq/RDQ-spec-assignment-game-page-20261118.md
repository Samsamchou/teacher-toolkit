# RDQ 需求規格：分配遊戲獨立頁

## 一句話任務
分配（練習／測驗）的課堂單人遊戲不再放在題目下方，改成獨立的遊戲頁，不捲動即可看到完整畫面與所有按鈕。

## 已確認
- 1A：只有獲得機會（全對 2、部分對 1）才翻到遊戲頁；答錯留在題目頁按「下一題」。依教師原意，答完後短暫顯示結果即自動翻頁，也可立即點按。
- 2A：用完機會後顯示本次得分，按「下一題」直接進下一題。
- 3A：以 iPad 橫向（1024×768）與電腦為主。
- 4B：測驗交卷後先看成績頁，按「去玩遊戲」翻到遊戲頁，玩完可回成績頁。
- 完成後直接部署正式站。

## 已採納建議
- ① 遊戲頁頂部狀態列：第 N 題・剩餘機會・遊戲總分；音量與靜音收進小按鈕。
- ② 遊戲畫面依螢幕高度縮放，操作按鈕固定在下方，一頁看完。
- ③ 遊戲頁重新整理或斷線後回到遊戲頁。
- ④ 以 1024×768、1180×820 逐款截圖驗收 5 款遊戲。
- ⑤ 課堂 Teacher-led 版面不改。

## 本次不納入
- iPad 直向最佳化；遊戲規則、機會與計分不變。

## 驗收條件
- [ ] 練習全對／部分對後翻到遊戲頁；答錯不翻頁。
- [ ] 5 款遊戲在 1024×768、1180×820 不捲動即可操作全部按鈕。
- [ ] 遊戲中重新整理回到遊戲頁；測驗成績頁可進出遊戲頁。
- [ ] Teacher-led 課堂遊戲版面不變；正式站部署讀回一致。
