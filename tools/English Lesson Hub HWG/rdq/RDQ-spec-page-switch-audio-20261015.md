# RDQ 需求規格：作答與遊戲分頁
已由使用者回覆「照這份開始，建議全部採納」確認，另追加遊戲音效豐富化。

## 已確認
- 國小學生使用的英語作答與六關 Godot 遊戲使用獨立畫面，按流程切換，減少整頁捲動。
- 作答頁呈現題目、媒體、作答、固定提交／重試／繼續操作；作答後呈現分數與獎勵。
- 遊戲頁呈現關卡、角色、戰鬥、血量與精簡道具列。
- 遊戲 → 英語挑戰 → 作答與領獎 →「回到遊戲」；最後一題進入既有華麗結算。
- 沿用六關、測驗／練習、重試、計分、獎勵與正式後台契約。
- 音效追加不同戰鬥、道具、切換及過關聲音與柔和的關卡音樂，提供音量與靜音控制。

## 已採納建議
- 作答時暫停遊戲並保留角色位置、血量與道具；返回時續玩，保留已載入的引擎。
- 固定主要操作；長題僅捲動內容區，保持可讀性。
- 短暫淡入淡出；尊重減少動態效果設定。

## 實作約定
- 同一分配連結內切換獨立畫面，避免每題重新下載 Godot；結果頁仍獨立呈現。
- 聲音使用本機程式合成，無外部付費生成或額外音效媒體下載。
- 本次修改本機預覽與下載品；正式部署及 Git 發布另需明確授權。

## 驗收條件
- [ ] 作答時不呈現遊戲；遊戲時不呈現作答區，桌機與平板無外層垂直捲動。
- [ ] 各題型的提交、重試與回遊戲按鈕持續可見，長內容可內部捲動。
- [ ] 切換不重建引擎、不遺失遊戲狀態、不重複計分或發獎。
- [ ] 音效可區分事件，支援背景音樂、音量、靜音；作答／隱藏分頁時戰鬥聲停止。
