# 專案基線 / Project baseline

- 我是國小英語老師 / I am an elementary English teacher.
- 所有檔案用繁體中文以及英文 / All project files use Traditional Chinese and English.
- 教學對象是國小 3–6 年級學生 / The teaching audience is Grade 3–6 elementary students.
- 專案名稱 / Project: **2026 listen read aloud videos**.
- 專案根目錄 / Project root: `G:\我的雲端硬碟\teacher-toolkit\tools\2026 listen read aloud videos`.
- 目標 / Goal: 分析參考單字韻文動畫，建立可換單字與圖片、以教師風格朗讀配合節奏的影片流程 / Analyze the reference chant and create a reusable vocabulary, image, voice, and rhythm workflow.
- 保存 `參考/` 原檔；分析、設定及候選成品使用不同資料夾與版本 / Preserve references and version all derived work.
- `analysis/` 保存分析及擷取證據；`rdq/` 保存需求卡；未確認新主題前不製作正式重製影片 / Save evidence in analysis and requirements in rdq; confirm the new topic before production.
- 沿用上層 teacher-toolkit Git，禁止建立巢狀 Git；初始化不提交或推送 / Use the parent Git repository; do not create nested Git or publish during initialization.
- API 費用、公開發布與雲端寫入依本次對話的明確授權 / Obtain task-specific authorization for API charges and publication.
- 人聲採 Speech API 內建聲線候選，不複製原片人聲；先試聽再確認 / Audition built-in Speech API voices without cloning the reference speaker.
- 2026-10-02 使用者明確指定「所有圖片都直接使用本機處理」；本專案提供的掃描圖、PDF 與單字圖片採本機擷取、保守去噪／銳化與 1:1 補白，不使用圖片 API，不重畫手寫或手繪 / User explicitly authorized local processing for all supplied project images; preserve strokes, text and colors without generative editing.
- 自動媒體檢查、動畫抽樣觀察與教師視聽驗收分開記錄 / Distinguish automated checks, sampled visual observations, and teacher audiovisual acceptance.
