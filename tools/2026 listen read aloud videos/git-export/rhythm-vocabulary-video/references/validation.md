# 驗收與失敗處理 / Validation

## 工具驗證

先確認Python可import numpy、PIL；PDF需fitz；語音處理需FFmpeg rubberband。字型必須存在，不能因字型缺失靜默換樣式。固定模板預設Comic Sans Bold，其他電腦缺此字型時請教師選可用字型或提供可合法使用的字型位置。

preflight核對所有圖片／背景／鼓聲／語音的SHA、配對、聲線、速度、錨點及鼓聲一小節長度。無效輸入應在建立正式輸出前停止。輸出資料夾已存在但沒有完整job紀錄時不覆寫；另存新版本。render的未完成嘗試保留，最多3個本機嘗試後先診斷。

## 成品檢查

1. 圖片與詞序：兩輪逐詞看實際編碼影格；16張兩輪圖可不同，依已核准映射驗證。逐詞檢查字幕一般小寫、Chinese／English首字母大寫、PE縮寫正確，總覽與朗讀畫面皆須相符。不能只確認字詞數量就宣稱圖片正確。
2. 聲音：每詞teacher→child各一次、完整尾音、無重疊；新語音逐詞ASR／聽校。兩輪可重用同詞音，但不可將老師音當兒童音。
3. 同步：計畫錨點對拍、實際分軌攻擊點及編碼讀回位移分別量測。`verify`以語音波形回找實際位置、獨立量測鼓聲攻擊點，再比較AAC附近視窗。整段AAC因有損壓縮採相關值>0.98，另要求逐詞語音位置≤1ms、標定錨點與鼓聲≤20ms、AAC位移≤5ms；不只依賴單一整段相關值。這仍不能單獨證明新語音的主重音選擇正確。
4. 畫面：只有黑板、圖卡及下方英文；無角色／速度／輪次字卡；圖卡尾音後才退場；長單字不截字、來源不拉伸。實際抽取片頭、輪次切換、尾段總覽：每輪8張必須4欄×2列、前4在上後4在下；9張為3欄×3列。verify另保存總覽影格及配對資料，需目視檢查文字不遮圖、不越界。
5. 媒體：完整影音解碼、1080p30／H.264／AAC、預期格數與片長、mix與AAC相關、無削峰。browser以1×播放、逐詞跳轉、結尾與手機版檢查；靜音自動播放不是教師聽感。
6. 局部修訂：若音軌應不變，比對AAC封包內容／PTS／DTS與完整解碼音訊；新圖不得改掉已通過節拍。
7. 32張：每段獨立QA與教師接受，合併接點檢查與再次完整解碼。測試資料的模擬接受紀錄不能用於正式影片。

## 技能本身的實測

- 8／9／16／32圖路由：來源順序、每輪圖片ID、每詞兩聲、長詞整拍延長、第一段／第二段邊界。
- 同詞不同圖、新詞／聲線缺檔、來源SHA改變、重複ID／檔名數字、錯誤速度、非法輸出路徑、未核准不同詞序皆須有可觀察結果。
- PDF與JPG實際擷取：正確頁面／座標／EXIF方向、無越界、原檔不變；PDF不是只驗證import成功。
- speech cache以安全的本機模擬HTTP做中斷／錯誤／重用驗證；不為技能測試額外付費生成或讀金鑰。
- 正式基準與生成測試分開。技能結構驗證器通過不等於影片功能正確；測試只報實際執行的項目。

瀏覽器自動檢查可執行`node scripts/check_preview.cjs SEGMENT_DIR`。需要Playwright及Chrome；可用`PLAYWRIGHT_MODULE`與`CHROME_PATH`指定本機安裝。它使用獨立暫時瀏覽器、靜音1×播放10秒、逐詞跳轉與結尾檢查；完整全片播放及有聲聽校另行記錄。技能不包入瀏覽器或Python套件。

verify重跑會保留QA-history-N.json及既有影格，新增版本；不能刪除失敗證據後宣稱首次通過。保存技能備份及安裝清單SHA，逐檔讀回確認相同。新工作階段是否已載入技能清單需實際觀察；安裝檔存在不宣稱目前對話已自動熱載入。
