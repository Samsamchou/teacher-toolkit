# 節奏單字朗讀影片製作

## 字幕位置規則（老師 2026-11-15 指定：之後所有動畫影片）
- 下方字幕整體比原本往上移 **56 px**（以 1080p 為準；720p 約 37 px）：字幕框底邊離畫面底邊至少 84 px，不貼著最下緣。
- 程式動畫（Canvas／HTML）改字幕框的 `bottom`；ffmpeg ASS 字幕把 `MarginV` 加 56（1080p）；其他排版工具同樣往上 56 px。
- 字幕若擋到人物臉，個別段落再移到左下或上方。
- 字幕上移後，畫面下方原本的字（片語、中文句意、選項、片尾大字）要一起往上移；出片前每 8 秒抽一格檢查有沒有被字幕蓋到（所有格動畫 v3 踩過）。

## 字體規則（老師 2026-11-10 指定：所有有字的動畫與影片）

> **本 skill 例外（老師 2026-11-13）**：朗讀影片的英文字 **Comic Relief 與 Comic Sans Bold 交替使用**，一支用一種、下一支換另一種，兩種都算合格。
> - 用 job 的 `font` 欄位切換：`C:/Windows/Fonts/comicbd.ttf` 或 `C:/Users/User/AppData/Local/Microsoft/Windows/Fonts/ComicRelief-Bold.ttf`。
> - 上一支用哪一種，記在專案的 `CLAUDE.md`。
> - 下面的「一律 Comic Relief」只適用其他影片流程。

- 畫面上所有英文字（字幕、句子、標籤、倒數數字、片頭片尾、字卡）一律用 **Comic Relief**（以 Bold 為主、Regular 為輔），不換成 Nunito、Arial、Comic Sans 等其他字體。
- 字型檔：`C:\Users\User\AppData\Local\Microsoft\Windows\Fonts\ComicRelief-Bold.ttf`、`ComicRelief-Regular.ttf`。網頁／Canvas／Three.js 先把字型檔複製進專案，用 `@font-face` 載入，等 `document.fonts.load(...)` 完成才截圖；ffmpeg ASS 字幕用 `subtitles=...:fontsdir=<含這兩個檔的資料夾>`，`Fontname=Comic Relief`。
- Comic Relief 沒有中文字：中文字幕、注音沿用該流程原本的中文字型，字型家族寫成 `'Comic Relief', <中文字型>`，英文用 Comic Relief、中文自動退回中文字型。
- 抽格檢查時確認字真的是 Comic Relief，不是瀏覽器預設字體。


## 現行課堂預設與本 skill 踩坑（2026-11，開工前必讀）

完整版（流程、素材位置、40 條「現象 → 原因 → 做法」）：[references/lessons-2026-11.md](references/lessons-2026-11.md)。

- **預設節奏＝Super Fun 模式**（老師 11/28：跟讀版「效果不好」）：128 BPM、前奏 4 小節、每張卡 2 小節（老師聲→兒童聲，第一個母音對第 1 拍）、片尾總覽每拍跳出；語音**原速 1.0**；伴奏本機 style 6＋換卡音效；−14 LUFS、伴奏 −6 dB、鼓 ×1.8；一支 11 張約 62 秒。參數見下方「Super Fun 節奏模式」。
- **流程**：RDQ（最多 3 題＋建議）→ 找素材並核對數量（老師說的數字可能不對）→ 卡片總覽給老師看 → 語音報價、老師同意才送 → ASR（small.en）＋修音＋錨點 → 20 秒樣本／試片 → 全片 → 老師說「確定為正式版」才登記。
- **卡片**：遊戲截圖用 `game.gd` 的 `CARDS=1` 模式（藏 UI 與浮動地名、多角度、2560 寬）；醜的模型用 Codex `-i` 重畫 2 版給老師挑；人物用 Andy 當畫風參考新畫；雙圖示用 512 px 原檔。
- **語音坑**：保守預留 US$0.02／段 → 分批；分批後 index 衝突 → 改名重建（0 請求）；tiny.en 會誤聽 → 用 small.en；TTS 真的唸錯（plays→praise、goes→those）或太長 → 老師同意後重生、instructions 加咬字或「one breath」提示；長停頓或 /s/ 拖長只剪靜音中段；格子式節奏要裁頭尾靜音（30／50 ms）、錨點用第一個母音起音。
- **音量坑**：−14 LUFS 要軟限幅（上限 −3 dBFS）；`wav()` 不准寫 ≥1，伴奏分軌和響度量測前要先縮放；`drum_gain` 只放大鼓。
- **工具坑**：Git Bash 會把 `/api/...` 參數轉成 Windows 路徑 → `MSYS_NO_PATHCONV=1`；Windows ffmpeg stderr 要 `encoding='utf-8', errors='replace'`；AI 音樂（KIE Suno 12 點／次）速度不準 → 逐小節 rubberband 對齊；`check_preview` 按鈕數要用字卡場景數。
- **改 skill**：先 zip 備份；改完用三支舊正式片重排時間軸，片長與朗讀次數要完全一樣；同步三份（`~/.claude/skills`、專案 `skills/`、`git-export/`）；`git-export` 的 SKILL.md 是 CRLF，用 `git -c core.autocrlf=false add`。

將教師提供的圖片與字詞製成可驗收的MP4。正式樣式源自教師已驗收的v05九科目影片；不是把九科目、90.17秒或特定學生座標固定套到所有新案。

- 配音：顯示文字和送 TTS 的文字分開（`TTS_FIX`），台詞不放「／」和音標；發音教學只用老師錄音或 Wikimedia；edge-tts 60 秒逾時＋重試 10 次；已變速的音檔不再變速；whisper 只抓時間，字幕照劇本，念錯與否給老師聽。
- 生圖：Codex CLI prompt 走 stdin（`codex exec ... -s workspace-write -i ref.png - < prompt.txt`），先輸出到 C 槽再複製，同時最多 3 張；圖上不放字（字、國旗、月曆用程式疊或 Commons SVG）；付費 API 先報價、老師同意上限。
- AI 短片：H3 照明只寫正向描述、要避免的東西連字都不寫；Seedance／KIE 只寫身體動作與空手、另列不准出現的東西、鏡頭固定；多出的片長用剪的不重生；KIE 先 480p 試 1 鏡，錯誤碼看 body 的 `code`。
- Blender：用座標改模型前 `view_layer.update()`；材質色是線性色彩；`transform_apply(location=False, rotation=False, scale=True)`；拼接物件合成單一網格（Freestyle 才不閃）；Tripo 家具黏住就換程式家具；Tripo 抓檔先 `--mark` 再按 Export、用三角面數核對；>15 萬面先 predecimate＋`use_persistent_data`；燈光換場景重調。
- Colab：Blender 只在 Colab；exec 只跑立刻返回的指令、渲染用分離執行、每 50 秒短 exec 保持連線、一鏡一批、渲完立刻下載；先建資料夾再上傳、上傳前 `ast.parse`；給老師看之前先停機；開機前報預估、做完報實際；不手改 `colab_usage.log`。
- 合成：不用 `-shortest`（先接無聲畫面再配完整音軌＋`apad`）；ffmpeg 9.0.1 不用 `-loop 1`、不用 `drawtext`、加 `-nostdin`；舊 .ogg 用 soundfile 解碼；配樂說話時比人聲低 18 dB、無配音段 1/4、整片 −16 LUFS（有閃避的混音不用 loudnorm）；前一句字幕早 0.2 秒結束；重點物件不放畫面下方 1/4。
- 交件：分鏡 → 試片 → 全片，每關等老師；改版只重做改到的段落、先交段落預覽、定案資料夾不動；聽力版只拿掉卡拉 OK 字幕；只交 1080p＋720p（720p 維持原畫質，不為 30 MB 壓縮）；自己先抽格，把可能被抓的地方先說出來，附用量與未驗證項目。
- 檔案：大量 PNG／影格／建置放 C 槽暫存，不放 G 槽；用腳本改字串先 `assert count == 1`、改完 `ast.parse`；不用 heredoc 寫程式；反斜線路徑會被吃成 tab 或響鈴字元，寫完讀回檢查。

## 正式預設與來源

- 1920×1080、30fps、H.264／yuv420p、AAC48kHz；黑板、圖卡下落／輕擺／上退及圖下英文。朗讀畫面不加老師／兒童、輪次、速度、題號或標題。
- 每輪**8張總覽固定4欄×2列**，上列前4張、下列後4張；片頭、輪次切換、尾段及32圖各分段都適用。每輪9張才用3欄×3列。
- 配對時檢查顯示字大小寫：一般單字全小寫（music、science），Chinese的C、English的E大寫，縮寫PE全大寫。不可照抄大寫檔名；原圖內學生手寫字不改。
- 每詞老師marin一次→兒童感coral一次；每段兩輪。coral為內建合成人聲的兒童感表現，不是真實兒童錄音或官方兒童聲線標籤。
- 語音0.85倍、保留音高；原模板鼓聲約93.673469 BPM。主重音對實測鼓聲，保留弱音節／前導音及尾音，長詞增加整拍。詳細方法見[語音與節奏](references/audio.md)。
- 所有圖片在本機處理，保留學生手繪、手寫、星期與著色，不外送圖片API、不生成重畫。見[裁圖方法](references/images.md)。
- `assets/baseline-profile.json`與`accepted-voice-bank.json`指向有SHA的私人正式資產；不內嵌學生作品、金鑰或字型。載入前核對來源存在與SHA；移動資料夾時明確更新路徑並保持雜湊核驗。
- 工作根目錄由本次使用者提供或目前專案決定，傳給`--project`；輸出須在其內。個人技能安裝目錄不當作新影片工作目錄。

## 依任務選擇流程

1. **素材整理**：先讀圖／頁面，建立單字與圖片配對；掃描件先用裁圖與補白工具，現成合格圖片可直接使用。
2. **新影片**：參閱[工作流程](references/workflow.md)，準備[設定格式](references/schema.md)，用工具preflight→plan→render→verify。沿用已選聲線，不重問A/B。
3. **新字詞語音**：先查同文字／模型／聲線／指令的已驗證快取；缺少才依本次授權生成。正常速度來源只變速一次，逐詞檢查頻譜與主重音候選，再做代表試片。
4. **局部修訂**：另存版本。只改畫面且語音／節奏指紋相同時，`render --reuse-audio`複製既有AAC；修改詞語或節奏時重排受影響內容並再檢查。
5. **32張合併**：兩段各有精確檔案SHA與教師明確驗收後才`merge`。新合併片仍需檢查接點並交教師驗收。

需求已清楚或正在修訂時直接做；不為了技能流程重問已知設定。主題／配對有實際歧義才詢問，繼續不依賴答案的工作。使用者指定RDQ時按已確認規格執行，不重跑訪談。

| 10 | `mode: three-rounds-ten-repeat`：同10張同序重複3輪，總覽5欄×2列（HWG7 U02正式版，60次朗讀） |
| 18（9+9） | `mode: two-rounds`：01–09第一輪、10–18第二輪，各3×3（502九科目正式版） |
| 18（6+6+6） | `mode: three-rounds-six`：三輪各6張，總覽3欄×2列（SF3 U02） |

| 24（6×4） | `mode: four-rounds-six`：四輪各6張，3×2；例：R1–R2 3D建築、R3–R4 同12字的雙圖示卡（二水小行星12地點正式版，2026-11-13） |

### Super Fun 節奏模式（2026-11-28，老師目前課堂用的節奏）

job 用 `"mode":"one-round"`（一支 1–12 張），加入 `"superfun": {"bpm":128,"t0":0.5,"intro_bars":4,"outro_bars":4,"card_lead":0.15,"style":6,"drum_gain":1.8,"backing_db":-6,"target_lufs":-14,"card_sfx":true}`，並把 `speech_speed` 設成 1.0。

- 前奏 4 小節（只有黑板）→ 每張卡 2 小節：第 1 小節老師聲、第 2 小節兒童聲，錨點（第一個母音起音）對齊小節第 1 拍 → 片尾總覽每拍跳出一張（11 張排 4＋4＋3）。
- 語音用原速：中間靜音超過 0.25 秒的縮成 0.15 秒，頭尾裁到起音前 30 ms、尾音後 50 ms。每句要放得進一小節（1.875 秒），相鄰兩句間隔 ≥ 30 ms。
- 伴奏：`style` 6 是本機合成的兒歌流行風（老師選定）。也可以用 `backing_file` 放外部伴奏（要先對齊 128 BPM），並用 `duck_db` 在人聲出現時壓低。
- 字尾紅字：item 加 `"red_spans": [[起,迄]]`，例如 watches 的 es 是 `[[5,7]]`；單張卡和總覽都會畫紅字。
- 人物＋圖示的合成卡要先做成 1024×1024 的圖再當卡片用（範例 `analysis/freetime-heshe-20261128/make_cards.py`）。
- verify 會加查：錨點在小節第 1 拍、每句在自己的小節內、相鄰人聲不重疊、11 張總覽 4＋4＋3。

### 跟讀模式（2026-11-14，Free Time v02 試做）

job 加入 `"follow_along": {"style":4,"backing_db":-6,"ding_gain":2.5,"drum_gain":1.8,"target_lufs":-14,"t0":0.6,"no_teacher_rounds":[4]}`（老師 11/14 嫌太小聲後的設定） 就會啟用跟讀模式，不加就是原本的「老師＋兒童」模式。

- 每個字 16 拍：老師 → 學生 → 兒童 → 學生，每段 4 拍。
- `no_teacher_rounds` 指定的輪次改成：學生 → 兒童 → 學生 → 空。
- 每段人聲都要放在自己的 4 拍格子內，錨點放在最早的整拍或半拍。
- 伴奏用 `scripts/backing.py` 在本機合成（style 4＝鼓＋拍手＋貝斯，學生拍第 1 拍加三角鐵），音量比人聲低 6 dB，整片響度拉到 −14 LUFS，並用軟限幅（上限 −3 dBFS）。
- 學生拍出現麥克風圖示、卡片隨拍輕跳。這是「畫面只有圖卡＋英文」規則的例外，老師已同意。
- verify 會改查：拍格、人聲在格子內、學生拍沒有人聲、每個字的角色順序、指定輪次沒有老師聲。

12／24張同字不同圖時用`round_word_policy: explicit`。18張有兩種切法，`auto`不會自動判斷，必須依教師指定寫明`mode`。

依檔名數字排序，不以英文字母排序；每張圖片使用明確的顯示字及發音文字。兩輪預設同詞同序，**若實際檔案不同，先列出差異；教師明確選擇依檔名／不同輪次內容時用`round_word_policy: explicit`，不得強制刪圖或替換單字。** 其他張數先釐清配對，不自行猜分組。
